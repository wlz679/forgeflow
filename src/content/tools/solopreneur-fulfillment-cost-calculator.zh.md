## 这个计算器衡量什么

单订单履约成本是**真正发出一个包裹的成本**——人工（拣货 + 打包）、运输、
包材，以及常被忽略的退货处理。大多数运营者会低估 30–50%，因为只算了
承运商报价，忘了拣/包人工或退货的隐性拖累。知道真实数字之后，你才能判断
3PL 报的 $5/单 是否真的比自建仓便宜，也能看清利润从购物车到签收之间
到底在哪里漏掉。

## 计算方法

v3 标准公式如下：

```
单订单人工 =（拣货分钟 + 打包分钟）/ 60 × 时薪
退货处理  =（退货率% / 100）× $4.50（行业均值）
单订单总  = 人工 + 运输 + 包材 + 退货处理
月度总    = 单订单总 × 月订单数
年度总    = 月度总 × 12
```

| 变量         | 含义                                                                  |
| ------------ | --------------------------------------------------------------------- |
| `月订单数`   | 用来把单订单成本放大到月度和年度                                      |
| `拣/包分钟` | 每个订单的拣货与打包工时（3 + 2 = 5 分钟/单 为典型值）                |
| `时薪`       | 拣/包工时费（美国典型区间 $15–25/小时）                              |
| `运输成本`   | 平均每单付给承运商的费用                                              |
| `包材成本`   | 纸箱、胶带、填充物、快递袋（典型 $0.50–$2.00/单）                     |
| `退货率`     | 退货订单占比；每单退货约耗 $4.5 接收、检验、重新入库或报废             |

健康度分档（单订单）：🟢 < $5 · 🟡 $5–$10 · 🟠 $10–$20 · 🔴 ≥ $20。
$5–$10 行业基准对齐 CSCMP 与 ShipBob 对中型 DTC 自建仓的统计；低于 $5
通常需要 3PL 规模或极致批拣。

## 局限性 / 何时不适用

$4.50 退货处理是**行业均值**——服装退货单件 $6–$10（换码 + 检验），
标品仅 $2–$3。如有自有审计数字请直接覆盖。多箱或大件 SKU（家具、设备）
需要单独计算器，因为承运商按体积重量计费而非一口价。纯服务型业务没有
履约可言，请直接跳过。

## 案例走读

一家 DTC 品牌月发 500 单，拣 3 分钟 + 包 2 分钟，运输 $5.5，包材 $1.2，
时薪 $18，退货率 8%：

1. `单订单人工` =（3 + 2）/ 60 × $18 = **$1.50/单**
2. `退货处理` =（8 / 100）× $4.50 = **$0.36/单**
3. `单订单总` = $1.50 + $5.50 + $1.20 + $0.36 = **$8.56/单** → 🟡
4. `月度总` = $8.56 × 500 = **$4,280/月** → **$51,360/年**
5. What-If：退货率降至 3% + 拣货提速 25% → 单订单降至 ~$8.00，
   **省 ~$340/月 或 $4,080/年**——通常够升级一条包装流水线。
