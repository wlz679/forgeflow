## 这个计算器衡量什么

时间是知识工作者唯一的不可再生资源，但大多数定价决策、是否接会、
外包与否的选择，都没有把小时时薪明确摆上桌。这个计算器把你的
年收入换算成 $/小时、$/分钟、$/秒，然后给会议、上下文切换、每日
时间浪费标上美元价格。它还告诉你按当前工时拿到 $200K、$300K、
$500K 年收入需要的小时时薪，并展示 4 天工作制下的等价收入。
搭配 Freelance Tax Calculator 看扣完自雇税后的真实时薪，搭配
Sponsorship Rate Calculator 把受众规模换算成单条美元。

## 计算方法

```
总小时数        = 每周工时 × 每年工作周数
小时时薪        = 年收入 / 总小时数
每分钟价值      = 小时时薪 / 60
每秒价值        = 每分钟价值 / 60
日价值          = 小时时薪 × 8
周价值          = 小时时薪 × 每周工时
月价值          = 年收入 / 12
工作日          = 每年工作周数 × 5
每日浪费 2h 年损 = 小时时薪 × 2 × 工作日         （每日 2 小时浪费）
上下文切换成本  = 小时时薪 × 0.5                  （30 分钟重新聚焦）
$200K 所需时薪  = 200,000 / 总小时数
```

| 变量            | 含义                                                                              |
| --------------- | --------------------------------------------------------------------------------- |
| `年收入`        | 目标或当前的年度总收入（税前）                                                    |
| `每周工时`      | 每周总工时（自由职业者要把不计费的行政时间也算进来）                              |
| `每年工作周数`  | 实际工作的周数（工薪族 48-50；自由职业者 44-46，因为有行政时间）                 |
| `总小时数`      | 派生 —— `每周工时 × 每年工作周数`                                                |
| `工作日`        | 派生 —— `每年工作周数 × 5`（假设 5 天工作制）                                     |

每日 2 小时浪费基准来自 RescueTime / DeskTime 知识工作者平均值；30 分钟
重新聚焦时长来自 Gloria Mark 的 UC Irvine 中断研究（Cal Newport《Deep
Work》也引用）。4 天工作制等价就是把同样年度工时重新摊到 4 天 —— 同样
收入、减少周数、降低 burnout 风险。有效时薪分档（🟢 ≥$200/hr、🟢
≥$100/hr、🟡 ≥$50/hr、🟠 ≥$25/hr、🔴 <$25/hr）参考 BLS 职业就业统计
的前 5% / 高于中位 / 中位 / 低于中位 / 入门级知识工作。

## 局限性 / 何时不适用

这个计算器假设你的年收入反映了有效产出工时 —— 这对工薪族成立，但
自由职业者不是：他们的计费工时只占总工时的 50-70%。不计费的 30-50%
（行政、营销、提案）让自由职业者的真实时薪比粗算低 30-40%。每日
2 小时浪费是行业平均 —— 长时间进入心流（写作、设计、工程）的角色
损失更少，被频繁打断的角色（销售、客服、运营）损失更多。如果你的
工作高度变化，先用 RescueTime 或 Toggl 做 2 周时间审计，再把时薪
当作 ground truth。4 天工作制投影还假设收入固定；对浮动收入或
佣金收入，会低估所需工时。

## 案例走读

独立咨询师，目标收入 $100,000，每周 40 小时，每年 48 个工作周：

1. `总小时数` = 40 × 48 = **1,920 小时/年**
2. `小时时薪` = $100,000 / 1,920 = **$52.08/小时**（$0.87/分钟，$0.014/秒）
3. `日价值` = $52.08 × 8 = **$416.67/天**
4. `周价值` = $52.08 × 40 = **$2,083.33/周**
5. `上下文切换成本` = $52.08 × 0.5 = **$26.04** / 次打断
6. `每日浪费 2h 年损` = $52.08 × 2 × 240 = **$25,000/年** 的生产力损失
7. 想在同样工时下达到 $200K/年，`$200K 所需时薪` = **$104.17/小时** —— 100% 提价，或每周加约 4 个计费小时

**Sponsorship Rate Calculator** 把受众规模换算成单条美元。一个好用的
后续规则：时薪一旦过 $50/小时，任何 $15-25/小时的外包或 VA 任务都
该立刻委派 —— 算账就是算账。
