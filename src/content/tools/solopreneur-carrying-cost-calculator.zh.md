## 这个计算器衡量什么

库存持有成本（carrying cost）是**持有库存的总年度成本**——仓储、保险、
损耗、机会成本，以及 3PL 计入持有费的其他一切项目。行业经验值（参
APICS 与 CSCMP 供应链参考）：持有成本约占平均库存价值的 **20–30%/年**。
低于 20% 表示资金高效；高于 30% 则意味着钱在货架上睡觉。

## 计算方法

v3 标准公式如下：

```
总费率        = 仓储 + 保险 + 损耗 + 机会 + 其他
年度总成本    = 平均库存 ×（总费率 / 100）
单项目成本_i  = 平均库存 ×（费率_i / 100）
```

| 变量         | 含义                                                                  |
| ------------ | --------------------------------------------------------------------- |
| `平均库存`   | 一段时间内（期初 + 期末）÷ 2 的库存价值                              |
| `仓储`       | 3PL / 仓库仓储费占库存价值百分比（一般 5–10%）                        |
| `保险`       | 库存保险费（一般 1–2%）                                               |
| `损耗`       | 失窃、损坏、过期、盘亏造成的损失（一般 1–3%）                        |
| `机会成本`   | 占用资金 × 替代投资回报率（信用额度 APR 或 WACC）                     |
| `其他`       | 跌价、报废、应分摊管理费                                              |

健康度分档：🟢 < 20% · 🟡 20–25% · 🟠 25–30% · 🔴 ≥ 30%。基准区间对齐
SCOR（供应链运作参考）模型中通用零售的「持有成本」分桶。

## 局限性 / 何时不适用

五费率模型假设你能把成本清晰拆解到 5 个桶里；中小 Shopify 卖家经常
把所有费用打包成「3PL 费」，无法拆分。**无实物库存的服务型业务应跳过
此计算器**——他们的机会成本应放在现金流预测里，而不是库存条目上。
该指标也是稳态口径：一次性 SKU 清仓会拉高当期损耗；3PL 合同重谈可能
永久压低仓储费率。

## 案例走读

一家中型 Shopify 品牌平均库存 $50,000。各项费率：仓储 8%、保险 1.5%、
损耗 2%、机会成本 8%、其他 2%：

1. `总费率` = 8 + 1.5 + 2 + 8 + 2 = **21.5%/年**
2. `年度总成本` = $50,000 × 0.215 = **$10,750/年**
3. 分档 = 21.5% → 🟡 **处于基准内（20–25%）**，年度复盘即可。
4. What-If：损耗降至 0.5%（防盗改善）→ 费率降至 20.0%，**省 $750/年**。
5. What-If：总费率下降 2pp → 19.5%，**省 $1,000/年**，进入 🟢 区，
   释放的 $1,000 资金按 8% 再投资每年额外 ≈ $80。
