## 这个计算器衡量什么

支付处理费是线上业务的隐形利润杀手。Stripe 标价是 2.9% + 30¢ 每笔，但实际有效费率随交易额（小额上固定费占大头）、国际卡（加 1.5% 附加费）、月交易量（$5 万 MRR 以上可谈）大幅波动。本计算器在任何交易额下比较 5 家处理商 —— Stripe US、Stripe International、PayPal、Square、Wise —— 投影月度 + 年度费用负担，并展示适合你具体场景的 **5 个最便宜降费杠杆**。

## 计算方法

费用拆解：

```
比例费 = 交易额 × 渠道百分比
固定费 = 0 或 30¢（渠道特定；hasFixed 标记）
总费用 = 比例费 + 固定费
净到账 = 交易额 − 总费用
有效费率 = 总费用 ÷ 交易额
```

| 渠道                  | 比例费 | 固定费 | 最适合场景                  |
| --------------------- | ------ | ------ | --------------------------- |
| Stripe US             | 2.9%   | 30¢    | 标准 SaaS / 电商            |
| Stripe International  | 4.4%   | 30¢    | 跨境卡交易                  |
| PayPal                | 3.5%   | 0¢     | 小额交易（< $5）            |
| Square                | 2.6%   | 10¢    | 线下 + 线上（一体化）       |
| Wise                  | 1.5%   | 0¢     | 美国境内转账（最便宜）      |

年度投影 = 月交易数 × 月总费用 × 12。节省场景：提价 $1、把费用转嫁给客户、切到年度计费（每年省 11 次固定费）、$5 万 MRR 谈判 0.5% 批量折扣、把 12 笔交易打包为 1 笔年度收费。

## 局限性 / 何时不适用

本计算器只覆盖 **标准卡交易**。它不建模：（1）ACH / 电汇费（Stripe ACH 通常 0.8% 上限 $5）；（2）拒付费（无论结果每笔争议 $15）；（3）货币转换费（以非账户币种收款 0.5%）；（4）订阅计费催收费；（5）Connect / marketplace 分账费。对高风险行业（CBD、博彩、成人），标准费率不适用 —— 处理商收 3.5-6% + 更高固定费。所示批量折扣为估算值；实际谈判取决于行业、拒付历史、处理量组合。切换前务必拿至少 2 家处理商的书面报价。

## 案例走读

假设一个 SaaS：每月 $100 订阅、通过 Stripe US 处理 100 笔交易。

1. **单笔费用** = $100 × 2.9% + $0.30 = **$3.20**
2. **月度总额** = $100 × 100 = **$10,000**
3. **月度费用** = $3.20 × 100 = **$320**
4. **年度费用** = $320 × 12 = **$3,840 / 年**
5. **Wise 对比**：$100 × 1.5% = **$1.50 / 笔** → $150 / 月，$1,800 / 年 —— 节省 **$2,040 / 年**
6. **如果你提价 $3（把费用转嫁给客户）**：净到账保持 $100，费用由买家承担

**What-If** 场景显示：纯境内业务切到 Wise 省最多，但对有国际客户的业务（Wise 跨境费率上涨），$5 万 MRR 时谈 Stripe 批量折扣更现实。配合 **SaaS 估值计算器** 看 $2K/年费用节省在 5 年退出窗口的复利效应。
