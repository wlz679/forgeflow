## 这个计算器衡量什么

离职成本（attrition cost）就是公司因失去一名员工而产生的**完全装载**
代价——花的、漏的，全算在内。它把三块成本合并：**招聘**（外部
recruiter 费、招聘平台、面试时间、sign-on bonus）、**上手**（新人
用数周时间以半产出状态顶岗）、**过渡期流失生产力**（团队和离职者
网络在过渡窗口的低效产出）。结果同时给出美元总额和相对年薪的
百分比——后者就是 SHRM 用来锚定「1.5x–2x 年薪」经验法则的指标，
也是把每位离职者送进留任复盘的硬门槛。

## 计算方法

```
招聘成本         = recruiting_cost
上手成本         = (年薪 / 52) × 上手周数 × 0.5
流失生产力成本   = (年薪 / 12) × 流失生产力月数 × 角色乘子

角色乘子 = 1.0（IC） | 1.5（Manager）

总成本      = 招聘 + 上手 + 流失生产力
占年薪百分比 = 总成本 / 年薪 × 100
```

| 变量                | 含义                                                              |
| ------------------- | ----------------------------------------------------------------- |
| `年薪`              | 该岗位年度底薪                                                    |
| `招聘成本`          | recruiter 费 + 招聘平台 + 面试时间 + sign-on bonus                |
| `上手周数`          | 新人达到产出所需周数（backfill 视角）                             |
| `流失生产力月数`    | 团队稳定期（典型 3–9 月）                                         |
| `岗位级别`          | `IC` 或 `Manager`（Manager 乘子 1.5x）                            |
| `占年薪百分比`      | 总成本占年薪比例（SHRM 锚定指标）                                 |

区间（百分比越低，留任越健康）：🟢 Excellent ≤50% — 精简离职成本，强
留任或低摩擦 backfill · 🟡 Good 50–100% — SHRM 典型区间，超 1.5x
年薪就应标记 · 🟠 Warning 100–200% — 流失风险集中在关键角色，要查
manager 任期 · 🔴 Critical >200% — 每一次离职都是重大经营事件。
`年薪 = 0` 返回 0%（除零保护）；所有输入截断非负。

## 局限性 / 何时不适用

本模型把离职当作**单次过渡事件**——它不建模离职者网络在 6 个月内
跟随离开的级联效应（SHRM 2022 引用 25–35% 的离职者会触发 ≥1 次
二次离职）。主动离职与被动离职**不**分开：被动通常上手成本更低
（背书决定更快）但招聘成本更高（声誉受损 + 离职补偿——按通行做法
把离职补偿并进 `recruiting_cost`）。上手期 50% 产出是平均假设——
要做更精细建模用 **生产力 Ramp 曲线计算器** 拟合曲线再积分整
个上手期。Manager 1.5× 乘子是实证值（SHRM 2022）且覆盖范围很宽
——VP 级离职可能是 2.5×；已知表现弱的经理辞职可能接近 1.0×。

## 案例走读

假设一名 IC 后端工程师 $120K 底薪离职：`年薪 = 120,000`，
`招聘成本 = 8,000`，`上手周数 = 12`，`流失生产力月数 = 6`，
`岗位级别 = IC`：

1. `招聘成本` = **$8,000**
2. `上手成本` = (120,000 / 52) × 12 × 0.5 = **$13,846**
3. `流失生产力成本` = (120,000 / 12) × 6 × 1.0 = **$60,000**
4. `总成本` = $8,000 + $13,846 + $60,000 = **$81,846**
5. `占年薪百分比` = 81,846 / 120,000 × 100 = **68.2%** → 🟡 Good（SHRM 区间内）

如果同一岗位换成 Manager 招：`角色乘子` = 1.5 → `流失生产力成本` =
120,000 / 12 × 6 × 1.5 = **$90,000** → `总成本` = $111,846 →
**93.2%** → 仍然 🟡 Good 但已经踩到上沿。从 68.2% 到 93.2% 的
40% 跳升就是 **Manager 税**——backfill 管理岗的真实预算线。要撞上
🟢 Excellent（≤50%）：要么把 `流失生产力月数` 砍到 ≤4（从流失生产力
省 $20K），**或者**按比例砍招聘和上手成本（例如把 $8K agency 换成
$5K 内推，省 2.5pp）。搭配 **完全装载成本计算器** 把 backfill 新人
的持续 overhead 算进 carry 分析，搭配 **股权刷新计算器** 算清留任
干预的 ROI。
