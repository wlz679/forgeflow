## 这个计算器衡量什么

管道覆盖率是管道总额与销售配额之比。它回答一个前瞻问题：*我有没有足够的管道打中目标？* B2B SaaS 经验法则——**3x 法则**——指出原始管道要达到配额的 3 倍才能稳定打中目标（因为即便 25% 赢率，0.75x 的加权管道对应约 75% 的达成概率）。Pavilion 2026 B2B 销售基准确认：跟踪 ≥3.0x 覆盖率的公司 80%+ 的时间能打中配额，而 1.0–2.0x 的公司只能 40–55% 打中。本计算器同时展示未加权覆盖率（3x 法则诊断）和加权覆盖率（按预期赢率调整）。

## 计算方法

我们使用的 v3 标准公式应用 HubSpot 3x 法则，并按赢率加权：

```
覆盖率           = 管道总额 ÷ 配额目标
加权管道         = 管道总额 × (赢率 ÷ 100)
加权覆盖率       = 加权管道 ÷ 配额目标
缺口             = 配额目标 − 加权管道
所需额外管道     = 缺口 ÷ (赢率 ÷ 100)
```

| 变量          | 含义                                                |
| ------------- | --------------------------------------------------- |
| `配额目标`    | 营收目标（季度、半年度、年度）                      |
| `管道总额`    | 所有阶段所有交易的当前在谈管道之和                  |
| `赢率`        | 历史关单率（%），仅用于加权                        |

**健康分档**（未加权覆盖率）：
- 🟢 ≥ 3.0x —— 优秀（达到 3x 法则；舒适缓冲）
- 🟡 2.0x–3.0x —— 良好（接近 3x 法则，盯紧阶段进度）
- 🟠 1.0x–2.0x —— 警告（低于 2x 舒适区；赢率下滑即风险）
- 🔴 < 1.0x —— 严重（管道不足，紧急重建管道顶端）

**假设。** 覆盖率计算把管道视为未加权（跨阶段面值）——这是 3x 法则的标准定义。赢率只用于加权覆盖率诊断。覆盖率采用近 90 天平均赢率；改用前瞻期（如下一季度）赢率会更前瞻但损失季节性平滑。

## 局限性 / 何时不适用

管道覆盖率为**B2B SaaS 或顾问式销售、周期长到无法在季度中重建管道**的业务设计。不适用于事务型或 PLG funnel（这些场景管道按小时而非按季度建立），也不适合 <90 天销售周期的业务——周期短的话管道快照一周内就过时。它还假设团队按统一口径上报管道金额（要么都加权，要么都不加权）——把 Discovery 加权与 Closing 未加权混在一起会扭曲比率。3x 法则适用于中等复杂度的 B2B SaaS（中端，50–200 名销售）；超长企业周期更安全的口径是 4x–5x（Forrester 2026）。

## 案例走读

一位 B2B SaaS AE 配额 $1,000,000，当前管道 $1,500,000，预期赢率 25%：

1. `覆盖率` = $1,500,000 ÷ $1,000,000 = **1.5x**（🔴 低于 2x 舒适区）
2. `加权管道` = $1,500,000 × 25% = **$375,000**
3. `加权覆盖率` = $375,000 ÷ $1,000,000 = **0.38x**
4. `3x 法则目标` = $1,000,000 × 3 = **$3,000,000**（还需 $1,500,000 管道）
5. `1x 盈亏平衡` = $1,000,000 ÷ 25% = **$4,000,000**（或在当前管道下赢率→ 67%）
6. 打到配额所需额外管道：$2,500,000（缺口 ÷ 赢率）
7. What-if：管道 $1.5M→$2M → 2.0x（🟡 Good）；赢率 25%→50% → 加权 0.75x（覆盖率仍 🔴，但加权管道翻倍到 $750K）；两者都做 → 2.0x 🟡、加权 $1M（稳稳在配额上）
8. 走向 🟢（3x）：需要管道 ≥ $3M（缺口 $1.5M）；仅靠赢率无法达到 3x（需要 200%——不可能）

搭配**管道价值计算器**看阶段质量，搭配**配额达成计算器**追踪节奏是否跟得上覆盖率。
