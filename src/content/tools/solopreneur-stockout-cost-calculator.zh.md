## 这个计算器衡量什么

缺货不只是丢一笔订单，更是**丢掉一个客户**。行业研究（Invensia, 2016）
显示 30–60% 遇到缺货页面的用户会转向竞争对手并不再回来。本计算器把
**当下收入损失**和**隐性的 LTV 流失**同时量化，并换算成占年营收的百分比，
便于与获客成本（CAC）放到同一张表上对比。

## 计算方法

v3 标准公式如下：

```
当期损失     = 日损失销售 × 缺货天数
LTV 损失     = 当期损失 × 客户流失率% × 客户 LTV ×（1 − 挽回率%）
总成本       = 当期损失 + LTV 损失
占营收比     = 总成本 / 年营收 × 100
```

| 变量         | 含义                                                                  |
| ------------ | --------------------------------------------------------------------- |
| `日损失销售` | 缺货期间每天损失的销售额（或件数 × AOV）                              |
| `缺货天数`   | 缺货窗口的平均持续时长                                                |
| `客户流失率` | 缺货后永久流失的客户比例（零售一般 30–60%）                          |
| `客户 LTV`   | 客户平均终身价值（不确定可用 LTV 计算器）                             |
| `挽回率`     | 通过邮件/广告挽回的客户比例（良好流程下 10–25%）                      |
| `年营收`     | 用于把缺货成本换算成占顶线比例                                        |

健康度分档（占年营收比例）：🟢 < 5% · 🟡 5–10% · 🟠 10–15% · 🔴 ≥ 15%。
基准参考 SCOR / CSCMP 关于零售服务水平的成本研究。

## 局限性 / 何时不适用

客户流失率是个**软输入**——大多数运营者并不直接测量。建议用问卷、A/B
邮件留资测试或行业代理值（保守 30%，标品 50%）。对易腐品（食品、生鲜）
而言，当期损失占主导，LTV 损失建模意义不大。纯服务型业务应直接跳过本
计算器——他们没有可缺货的 SKU。

## 案例走读

一家 DTC 品牌缺货期日损销售 $1,000、平均 5 天、客户流失率 30%、LTV $200、
挽回率 10%、年营收 $600,000：

1. `当期损失` = $1,000 × 5 = **$5,000**
2. `LTV 损失` = $5,000 × 0.30 × $200 × (1 − 0.10) = **$270,000**
3. `总成本` = $5,000 + $270,000 = **$275,000/年**
4. `占营收比` = $275,000 / $600,000 = **45.83%** → 🔴 关键。
5. What-If：缺货天数砍半 + 挽回率提到 25% → 总成本降至 ~$115,000，
   **省 ~$160,000/年**——足够为前 3 大 SKU 启动多供应商试点。
