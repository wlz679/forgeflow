## 这个计算器衡量什么

Cart Abandonment Cost（购物车放弃成本）计算器建模被放弃购物车的
**机会成本**（损失收入）以及针对这些购物车的**挽回活动 ROI**
（邮件 + SMS 再营销）。它输出 8 个独立指标：月损失收入、可挽回收入、
挽回成本、挽回净收益、挽回 ROI、盈亏平衡挽回率，以及在当前和改进
挽回率下的年度预测。在评估新的 Klaviyo / Postscript 流程、为挽回
预算辩护、或建模改进结账 UX 的财务可行性时使用。

## 计算方法

我们使用的 v3 标准公式（Baymard / Shopify / Klaviyo 标准）：

```
加购数          = 月流量 × (加购率 / 100)
完成订单数      = 加购数 × (1 − 弃单率 / 100)
弃单数          = 加购数 × (弃单率 / 100)
损失收入        = 弃单数 × 客单价
可挽回收入      = 损失收入 × (挽回率 / 100)
挽回成本        = 弃单数 × 单次发送成本
挽回净收益      = 可挽回收入 − 挽回成本
挽回 ROI        = 可挽回收入 / 挽回成本
盈亏平衡挽回率 = 挽回成本 / 损失收入 × 100
```

| 变量              | 含义                                                              |
| ----------------- | ----------------------------------------------------------------- |
| `月流量`          | 每月店铺总访客数（所有来源）                                      |
| `加购率`          | 访客中加过购物车的百分比                                          |
| `弃单率`          | 加购后未完成结账的百分比（Baymard 2024 平均 70.19%）             |
| `客单价`          | 完成订单的平均金额                                                |
| `挽回率`          | 邮件/SMS 挽回的弃单百分比（Klaviyo 平均 8%）                     |
| `单次发送成本`    | 每条弃单消息的成本（ESP + SMS + 文案，0.10–2.00 元）              |

健康分带（挽回 ROI）：🟢 ≥ 300% · 🟡 200–300% · 🟠 100–200% · 🔴 < 100%。

## 局限性 / 何时不适用

挽回率因**渠道不同会差 2–3 倍**：纯邮件约 8%，SMS 主导约 20–30%，
推送 + 邮件约 15%（Klaviyo 基准）。计算器只有一个 `挽回率` 输入
——如果跑邮件 + SMS，请按**实际混合**挽回率填，不要填邮件那一个
基准。另外，单次发送成本是**变动**成本——不含 ESP / SMS 平台固定
费（Klaviyo + Postscript 大约 300–1,000 元/月），所以低流量店铺
的真实 ROI 比计算器更难看。同时跑付费再营销广告时，请搭配 **ROAS**
工具。

## 案例走读

某 DTC 服饰店月流量 50,000，加购率 20%，弃单率 70%，客单价 80 元，
邮件挽回率 8%，每封挽回邮件成本 0.50 元：

1. `加购数`       = 50,000 × 0.20  = **10,000**
2. `完成订单数`  = 10,000 × 0.30  = **3,000**
3. `弃单数`       = 10,000 × 0.70  = **7,000**
4. `损失收入`    = 7,000 × 80     = **560,000 元/月**
5. `可挽回收入`  = 560,000 × 0.08 = **44,800 元/月**
6. `挽回成本`    = 7,000 × 0.50   = **3,500 元/月**
7. `挽回净收益`  = 44,800 − 3,500 = **41,300 元/月**
8. `挽回 ROI`    = 44,800 / 3,500 = **12.8x = 1,280%**（🟢 优秀）
9. `盈亏平衡挽回率` = 3,500 / 560,000 = **0.625%**——活动只要挽回
   0.6% 的弃单就回本（行业平均 8%，约 13 倍安全垫）

Dashboard 的 What-If 建模："加 SMS 后混合挽回率从 8% 升到 18%，
挽回净收益从 41,300 涨到 97,300 元/月（+56,000 元增量），ROI 仍然
过 1,000%。" 挽回流程里带折扣码时，请搭配 **Coupon Attribution
（优惠券归因）** 工具——折扣会拉低净毛利，并可能自损正价订单。
