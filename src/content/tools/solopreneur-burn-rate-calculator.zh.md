## 这个计算器衡量什么

烧钱速度是公司花掉现金储备的节奏。**毛烧钱**是每月总运营支出（人员、基础设施、市场、运营）；**净烧钱**在这个总额上扣掉经常性收入，才是银行账户实际在缩水的速度。配合现金余额，烧钱速度可以算出**跑道**（按当前烧钱还能撑几个月）和 Paul Graham 推广的 **Default Alive / Default Dead** 判定——不主动干预的话，下一轮融资或到达盈亏平衡时公司还活着吗。

## 计算方法

我们使用的 v3 标准公式：

```
毛烧钱 = 人员成本 + 基础设施 + 市场 + 运营
净烧钱 = 毛烧钱 − 月收入
跑道月数 = 当前现金 ÷ 净烧钱
Burn Multiple = 净烧钱 ÷ 当月净增 MRR
```

| 变量         | 含义                                       |
| ------------ | ------------------------------------------ |
| `人员成本`   | 全包月工资（薪资、外包、五险一金）         |
| `基础设施`   | 托管、SaaS 工具、第三方 API、云存储        |
| `市场成本`   | 付费投放、内容生产、市场工具、代理费       |
| `运营成本`   | 办公室、律师、保险、会计、出差、杂项      |
| `月收入`     | 平均月经常性收入（3–6 个月平均更准）       |
| `净增 MRR`   | 月环比净增 MRR（新增 + 扩展 − 流失）       |
| `当前现金`   | 经营账户的活期余额                         |

**假设。** 跑道公式按净烧钱不变计算——不会建模招聘爬坡、季节性收入或融资事件。净增收入按月一次性入账，不是平滑流水。盈亏平衡是从当前缺口线性外推，真实增长通常非线性，所以给出的盈亏平衡日是粗估，不是承诺。

## 局限性 / 何时不适用

这个计算器为**订阅制公司和成本可预测的初创公司**设计。如果你的业务是项目制、零售或批发（收入波动大、销货成本月月不同），跑道数据会误导。这类业务应使用考虑应收账款节奏和库存周转的现金流预测。烧钱速度还假设你可以立刻砍掉可自由支配支出——如果有固定成本（租约、遣散条款）锁死，请相应调整**砍成本场景**。

## 案例走读

一家 B2B SaaS 月收入 $5,000，人员 $8,000，基础设施 $500，市场 $2,000，运营 $1,500，银行里 $50,000，每月净增 MRR 约 $3,000：

1. `毛烧钱` = 8,000 + 500 + 2,000 + 1,500 = **$12,000/月**
2. `净烧钱` = 12,000 − 5,000 = **$7,000/月**（年化 $84,000）
3. `跑道` = 50,000 ÷ 7,000 = **约 7.1 个月**——现金大概在明年 3 月归零
4. `Burn Multiple` = 7,000 ÷ 3,000 = **2.3×**（🔴 红灯区，增收速度跟不上烧钱）
5. 判定：**12 个月内 Default Dead**——需砍掉 $2,000/月成本或让净增 MRR 翻倍才能把跑道拉到 12 个月以上
