## 这个计算器衡量什么

薪酬带（comp banding）把一个 offer 底薪对到市场百分位基准（P25、P50、
P75），告诉你**你站在哪**。输出是一个 0–100 之间的连续百分位——
不是档位标签——这样你能看清 offer 究竟在 P50 以上多远、或离 P75 差多远。
按 P75 付是顶四分位的留任信号（LinkedIn / Pave 2024 引用 P75 比 P50
的主动流失风险低约 40%）；按 P25 以下付就是流失紧急事件——对方通常
6 个月内就会有竞争对手的 counter-offer。这是你的 People Ops 和 Finance
在候选人谈判开始前用来**报价防守**用的计算器。

## 计算方法

```
百分位 = 分段线性插值(底薪, 市场 p25/50/75)

如果 base ≤ p25:   pct = (base / p25) × 25
elif base ≤ p50:   pct = 25 + ((base − p25) / (p50 − p25)) × 25
elif base ≤ p75:   pct = 50 + ((base − p50) / (p75 − p50)) × 25
else:              pct = min(100, 75 + ((base − p75) / p75) × 25)
```

| 变量        | 含义                                                                |
| ----------- | ------------------------------------------------------------------- |
| `角色`      | 角色名（上下文用，不进入数学）                                      |
| `底薪`      | offer 年度底薪                                                      |
| `市场 p25`  | 该角色/地区底薪的 P25（来源：Pave / Levels.fyi）                    |
| `市场 p50`  | P50（中位数）                                                       |
| `市场 p75`  | P75                                                                  |
| `百分位`    | offer 在 P 序中的落点（0–100，封顶）                                |

区间（越高越有竞争力越好）：🟢 Excellent ≥P75 — 顶四分位留任信号 ·
🟡 Good P50–P75 — 有竞争力但尚未顶四分位 · 🟠 Warning P25–P50 —
低于市场 median，对手开出 P50+ 会触发流失 · 🔴 Critical <P25 — 显著
低于市场，6 个月内会遭遇 counter-offer。输入截断非负；P25/P50/P75 三
者相同时（退化基准）直接返回 25/50/75。

## 局限性 / 何时不适用

这是**仅底薪**口径——不包含奖金、股权（RSU/期权）或 sign-on。总薪酬
百分位需要另一套模型：NPV 折现股权 + 奖金期望值（Pave 和 Carta 都有
总薪酬切分，但数学完全不同）。地理调整是硬性要求：SF Bay 的 P50 大致
**等同于**美国大多数地方的资深工程师——用 Pave / Levels.fyi 的地理
筛选，不要用全国中位数。P75 以上的百分位是粗粒度的线性外推——对留任
关键人走到 P85–P95 合理，但你很可能付多了。搭配 **股权刷新计算器**
做好 cash 与 equity 的平衡。

## 案例走读

假设一个资深软件工程师的 offer，`底薪 = $160,000`，
`市场 p25 = $130,000`，`市场 p50 = $155,000`，`市场 p75 = $185,000`：

1. `底薪 $160,000` 落在 P50 ($155K) 与 P75 ($185K) 之间
2. `百分位 = 50 + ((160,000 − 155,000) / (185,000 − 155,000)) × 25 = 50 + (5,000/30,000) × 25 = 50 + 4.17 ≈ 54.2 → P54`
3. 档：**🟡 Good（P54）** — 高于市场 median，距 P75 差 $25K
4. 到 P75 的差额 = $185,000 − $160,000 = **$25,000**
5. P75 的留任收益：Pave 2024 引用主动流失率较 P50 降约 40%

如果候选人反价到 P75 预算（$185K），People Ops 现在有 $25K 现金差要
决定——批（顶四分位留任）或借 **股权刷新计算器** 用股份补差额
（典型 0.10–0.20% 稀释）。如果你的 `P50` 是**未做地理调整**的源
而候选人在 SF，实际 P75 可能更接近 $215K——报价前先用 SF Bay filter
重拉一次。
