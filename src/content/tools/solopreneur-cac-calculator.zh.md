## 这个计算器衡量什么

获客成本（CAC）是赢取一位新付费客户所需的全部销售与市场费用。本计算器把跨渠道的混合 CAC 隔离出来，再算出 **CAC 回收期** —— 即用毛利回收这笔获客投入需要几个月。孤立的 CAC 没有意义：$500 的 CAC 若 LTV 是 $3,000 是优秀，若 LTV 只有 $300 就是灾难。务必把 CAC 和 LTV:CAC（目标 ≥ 3:1）、回收期（目标 ≤ 12 个月）放在一起评估。

## 计算方法

v3 混合 CAC 公式：

```
CAC     = （市场费用 + 销售费用）÷ 新增客户
毛利    = 平均收入 × （毛利率 ÷ 100）
回收期  = CAC ÷ 毛利（月）
```

| 变量         | 含义                                          |
| ------------ | --------------------------------------------- |
| `市场费用`   | 付费广告、内容、SEO 工具、活动、市场人员工资 |
| `销售费用`   | SDR/AE 工资、佣金、销售工具、CRM 授权         |
| `新增客户`   | 同期净新增付费客户数                          |
| `毛利率`     | 扣除 COGS 后的收入百分比                      |
| `平均收入`   | 每位客户每月收入                              |

计算器把混合 CAC 对标 SMB（$100-300）、中端市场（$300-700）、企业级（$700+）三档。**情景条** 在保持转化率不变的前提下建模 5 个支出层级（砍 50% → 加 200%），展示规模化获客支出到底是改善单位经济还是单纯抬高 CAC。

## 局限性 / 何时不适用

混合 CAC 会掩盖渠道级差异：你的 SEO 渠道可能是 $50 CAC，而 LinkedIn 广告是 $500 —— $200 的平均看起来还行，却隐藏着预算分配问题。务必通过 UTM 参数 + CRM 线索来源为每个渠道单独埋点 CAC。本计算器也不包括创始人在销售通话上的时间（对单人创业者来说往往是最大单项支出）—— 按你的小时费率 × 每月销售小时数计入隐含工资。对尚未创收、$0 市场费用的初创公司，CAC = $0 形式上正确但误导：自然口碑背后有隐性机会成本。

## 案例走读

假设一个 B2B SaaS：每月 $5,000 投入 Google Ads + 内容、$3,000 投入兼职 SDR、每月新增 40 位客户、ARPU $50/月、毛利率 80%。

1. **总投入** = $5,000 + $3,000 = **$8,000**
2. **CAC** = $8,000 ÷ 40 = **$200 / 客户**
3. **单客户毛利** = $50 × 80% = **$40 / 月**
4. **回收期** = $200 ÷ $40 = **5.0 个月** —— 健康（低于 12 个月目标）
5. **首年价值** = $50 × 12 × 80% = **$480 / 客户** → 3:1 LTV 目标 = **$600**

如果砍 25% 预算（聚焦最佳渠道）：$6,000 ÷ ~30 客户（成比例）= $200 CAC，但客户总数减少。情景条展示你应该 **扩预算**（回收期在高预算下仍 < 12 个月时）还是 **集中预算**（最佳渠道上）。
