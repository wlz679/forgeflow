## 这个计算器衡量什么

一个能赚钱的自由职业项目，指的是**有效小时费率**——总收入除以
总工时——超过你的目标费率，并且有足够利润率消化范围蔓延、修改和
行政开销。本计算器把项目收入、预估工时、内部小时成本、材料 / 工
具成本，转成净利润、利润率、有效小时费率、以及覆盖成本所需的盈亏
平衡小时费率。它还按 1×/2×/4× 每月节奏预测年化利润，并展示 9 个
不同小时成本下的盈亏全貌。它面向正在评估要不要以某个报价接项目的
自由职业者和小工作室。

## 计算方法

时间追踪工具通用的标准项目成本模型：

```
总人力成本       = 预估工时 × 小时成本
总成本           = 总人力成本 + 材料成本
净利润           = 项目收入 − 总成本
有效小时费率     = 项目收入 ÷ 预估工时
成本回收小时费率 = 总成本 ÷ 预估工时
利润率           =（净利润 ÷ 项目收入）× 100
成本乘数         = 有效小时费率 ÷ 小时成本
盈亏平衡工时     = 总成本 ÷ 有效小时费率
盈亏平衡费率     = 总成本 ÷ 预估工时
```

| 变量              | 含义                                            |
| ----------------- | ----------------------------------------------- |
| `项目收入`        | 客户支付的总费用（税前）                        |
| `预估工时`        | 范围蔓延前的工时估算                            |
| `小时成本`        | 内部成本费率（机会成本或工资底线）              |
| `材料成本`        | 第三方成本（素材、外包、特定软件）              |
| `有效小时费率`    | 收入 ÷ 工时——每小时真实价值的衡量              |
| `成本乘数`        | 有效费率相对成本费率（目标 ≥2x）                |

**假设。** `预估工时`按完工后的现实数字处理——多数自由职业者会低
估 20-30%，所以计算器的「Tip」建议在信任估算前先做 3 个月实际追
踪。`小时成本`是**成本**不是你的开票价：它等于你做别的事能赚到的，
或维持生活的工资底线。`材料成本`不含日常开销（房租、宽带、通用软
件）；那些属于公司级 P&L，不是单项目利润率。模型假设单一交付——
多阶段项目请拆分后分别建模。

## 局限性 / 何时不适用

本计算器建模的是**单一项目利润**。它不适合 retainer 利润（月收
入固定、利用率变化）、订阅型产品利润（边际成本随交付规模下降）、
或团队利润（要叠加销售、项目管理、行政时间的利用率折扣，自由职
业者不背这些）。它也不建模**税务**：美国自由职业者要在所得税之外
另交约 15.3% 自雇税，所以一个净赚 $2,800 的项目扣完自雇税大概真
正到手 ~$2,300。国际自由职业者应把成本项加上 VAT、GST 或等价销售
税。

## 案例走读

一位自由网页设计师接了一个 $5,000 的品牌网站项目，预估 40 小时
工时，内部成本费率 $50/小时（机会成本），并要花 $200 买素材照片和
一套高级字体授权：

1. `总人力成本` = 40 × $50 = **$2,000**
2. `总成本` = $2,000 + $200 = **$2,200**
3. `净利润` = $5,000 − $2,200 = **$2,800**
4. `利润率` = $2,800 ÷ $5,000 = **56%**（健康——超过 30%）
5. `有效小时费率` = $5,000 ÷ 40 = **$125/小时**（远超 $50 成本费率）
6. `成本乘数` = $125 ÷ $50 = **2.50×**（高于 2× 可持续阈值）
7. `盈亏平衡工时` = $2,200 ÷ $125 = **17.6 小时**（占预估工时 44% 即保本）
8. `年化` = $2,800 × 12 = **$33,600/年**（如果每月来一个一样的项目）

计算器的 what-if 场景显示，砍掉 20% 预估工时（效率提升）把利润
推到 **$3,400（利润率 68%）**；涨价 15% 推到 **$3,550（利润率
61.7%）**；二者叠加能拿到 **$3,550** 同时省出时间。按 4×/月 节奏
同一经济学放大，年利润到 **$134,400/年**——满产管线级别。搭配
**Freelance Rate Calculator** 确认你的 $50/小时成本费率本身站得
住，再搭 **Hourly vs Fixed Calculator** 验证项目报价改成小时计费
是否仍然成立。
