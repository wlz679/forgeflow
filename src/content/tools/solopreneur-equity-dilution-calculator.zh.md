## 这个计算器衡量什么

股权稀释衡量一轮投资如何降低现有股东的持股比例。每一轮定价融资都会稀释创始人、早期投资人、期权池 —— 而且稀释往往比天真数学显示的要大，因为大多数轮次还包含 **扩大的期权池**，从 pre-money 估值里出。本计算器建模：投后估值、创始人与投资人持股分配、期权池影响（默认 10%），以及 5 个估值情境下的创始人退出所得。

## 计算方法

稀释瀑布：

```
投后估值    = pre-money 估值 + 投资额
投资人持股  = 投资额 ÷ 投后估值（占公司 %）
投资人股数  = 创始人股数 × （投资额 ÷ pre-money 估值）
投后总股数  = 创始人股数 + 投资人股数
创始人持股  = 创始人股数 ÷ 投后总股数（投后）
稀释比例    = 100% − 创始人持股

期权池影响  = 10% 池 → 创始人有效持股进一步下降
             池后创始人 = 创始人股数 ÷（投后总股数 + 池股数）
```

| 变量             | 含义                              |
| ---------------- | --------------------------------- |
| `Pre-money 估值` | 本轮投资前公司价值                |
| `投资额`         | 本轮进入的新现金                  |
| `创始人股数`     | 当前已发行的创始人股份总数        |

创始人控制阈值：> 60% 强控制；40-60% 少数（警惕一票否决权）；20-40% 失去多数；< 20% 少数持股，投资人很可能控制董事会。

## 局限性 / 何时不适用

本计算器使用简化的 **单类股份结构**。它不建模：（1）优先股清算优先权（1x 不参与是标准；2x 或参与优先权显著改变退出瀑布）；（2）反稀释条款（加权平均 vs 完全棘轮）；（3）现有投资人的 pro-rata 权利；（4）顾问股与 ESOP 授予。对可转债 / SAFE 轮次，稀释不会立即发生 —— 用 **SAFE / 可转债计算器**。本计算器假设单轮定价融资 + 固定 10% 期权池；真实轮次常包含 15-20% 期权池扩张作为先决条件，新投资人股数甚至还没计入前就进一步稀释了创始人。

## 案例走读

假设一家初创公司：$500 万 pre-money 估值，融资 $100 万，已发行 1,000 万创始人股。

1. **投后估值** = $500 万 + $100 万 = **$600 万**
2. **投资人持股** = $100 万 ÷ $600 万 = **16.67%**
3. **投资人股数** = 1,000 万 × （$100 万 ÷ $500 万）= **2,000,000 股**
4. **创始人持股** = 1,000 万 ÷ 1,200 万 = **83.33%**（稀释 16.67%）
5. **期权池（10%）**：创始人进一步降到 **75.00%** 有效
6. **$5,000 万退出（10× pre-money）**：创始人得 75% × $5,000 万 = **$3,750 万**

如果你把 pre-money 谈到 $625 万（高 25%）：稀释降到 13.79%，创始人有效保持 79.17% —— 省 ~3 个百分点，并向未来投资人传递动能信号。What-If 段建模融一半（$50 万）只要 9.09% 稀释 —— 如果你想保留更多所有权可用此选项。
