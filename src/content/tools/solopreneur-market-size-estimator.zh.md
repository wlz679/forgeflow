## 这个计算器衡量什么

市场体量估算是给"你**可能**服务的买家"一个具体数字，并把它拆成投资人/经营者决策用的三层。**TAM（潜在市场总额）**是假设每个潜在买家都从像你这样的供应商处购买时的全球年收入；**SAM（可服务市场）**是考虑你的地理、渠道、产品约束后真正能触及的切片；**SOM（可获取市场）**是你在未来 2–3 年实际能拿下的部分。本计算器同时给出**自下而上**（客户数 × 客单价）和**自上而下**（TAM 的市场份额）两个视角，并在两者发散时给出警告。

## 计算方法

我们使用的 v3 标准公式：

```
TAM        = 潜在客户总数 × 人均年收入
SAM        = TAM × SAM 占比 ÷ 100
三年后市  = TAM × (1 + 增长率)^3
五年后市  = TAM × (1 + 增长率)^5
自下而上收入 = 潜在客户数 × 渗透率 × ARPU
自上而下收入 = TAM × 市场份额 × 市场阶段调整
```

| 变量               | 含义                                       |
| ------------------ | ------------------------------------------ |
| `目标市场`         | 自由文本市场名（如"美国独立牙科诊所"）    |
| `潜在客户总数`     | 潜在买家数量（B2B：企业数；B2C：终端用户） |
| `人均年收入`       | 平均年度合同金额（或 ARPU × 12）           |
| `市场年增长率`     | 市场年复合增长率 CAGR                      |
| `SAM 占比`         | 用你的 GTM 能触及的 TAM 比例               |
| `市场阶段`         | 新兴 / 成长 / 成熟 / 衰退——调整可达性      |
| `渗透率`           | 2–3 年内的预期市场份额（按市场规模分档）   |

**假设。** 自下而上假设客单价在客户群里统一——如果有分段定价，请用加权平均。自上而下应用**市场阶段调整**（新兴 ×1.5，成长 ×1.0，成熟 ×0.7，衰退 ×0.4）来反映每个阶段拿份额的难度。如果自下而上和自上而下相差 3 倍以上，说明输入参数需要回到一手研究校验。

## 局限性 / 何时不适用

市场体量估算是**方向性**练习，不是预测。这个计算器用 ARPU × 客户数——如果你的市场是真正的双边平台（例如买卖双方都有的 marketplace），你需要交易额模型。它还假设你真的能触达整个 SAM；现实中，分销约束（渠道伙伴、语言壁垒、监管牌照）通常会砍掉一半。用**自上而下交叉验证**给投资人讲故事之前先 sanity-check 自下而上的输入。

## 案例走读

一家 SaaS 瞄准"美国独立牙科诊所"，共 30,000 家诊所，ARPU $5,000，市场 CAGR 12%，SAM 25%，市场阶段为"成长"：

1. `TAM` = 30,000 × $5,000 = **$150M/年**
2. `SAM` = $150M × 25% = **$37.5M/年**（你 GTM 能覆盖的诊所）
3. `三年后市` = $150M × 1.12³ = **$210.7M/年**（复利）
4. 自下而上 1% 份额：30,000 × 0.01 × $5,000 = **$1.5M/年**（小团队可冲的目标）
5. 自上而下 1% TAM（无阶段调整）：$150M × 0.01 = **$1.5M/年**——与自下而上收敛
6. 触达 $100K/年需要 20 个客户——只是 TAM 的 0.07%，稳稳落在 🟢"易达成"区间
