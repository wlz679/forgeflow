## 这个计算器衡量什么

文档投资回报衡量知识库是否回本——把工单分流的节省换算成投资回报倍
数。一个 $15,000/月 的知识库若能在 $24/张的工单成本下分流 1,750 张工
单，每个月可节省 $42,000 毛额——净节省 $27,000/月——也就是 180% ROI。
这个指标迫使文档经理用美元而不是文章篇数来为知识库预算辩护，把内容
团队的工作直接绑到 CS Ops 的损益表上。TSIA 的 Knowledge-Centered
Service 框架把成熟的知识库视为利润中心而非成本中心，本计算器就是那
张收据。

## 计算方法

```
毛节省     = 每月分流工单 × 每张工单成本
净节省     = 毛节省 − 知识库团队月度成本
ROI        = (净节省 ÷ 知识库团队月度成本) × 100
每篇文章月成本 = 知识库团队月度成本 ÷ 文章总数
```

| 变量               | 含义                                       |
| ------------------ | ------------------------------------------ |
| `知识库月度成本`   | 全负荷写作者 + 工具 + 管理费用的月度开销   |
| `每月分流工单`     | 每月通过自助渠道关闭的工单数               |
| `每张工单成本`     | 每张已处理工单的混合人工成本               |
| `知识库总文章数`   | 现役文章数（决定每篇文章成本）             |
| `目标 ROI%`        | 内部目标——驱动盈亏平衡行                  |

健康等级（顶部为复合 AND 逻辑，其余为单指标）：🟢 Excellent（ROI
≥400% 且每篇文章成本 ≤$50/月）· 🟡 Good（ROI ≥150%）· 🟠 Warning（ROI
≥50%）· 🔴 Critical（ROI <50%）。

## 局限性 / 何时不适用

Excel 时代最常见的坑：每张工单成本必须是**全负荷**成本（坐席工资、培
训、工具、管理费用、办公支出）除以已处理工单数，而不是单纯的人工时薪
成本。中型 B2B SaaS 普遍在 $15-$40/张（Zendesk 2024）；如果只用 $8
（仅 Tier-1），ROI 会被高估 3-4 倍。另外 ROI = 0% 并不等于"知识库失
败"——全新知识库可能文章量还没攒起来，分流能力有限。请把这个指标当
作过去 6 个月的滚动平均来看，单月快照意义不大；前 3-6 个月是爬坡期。
每篇文章月成本 ≤$50 意味着编辑成本被摊薄到了足够多的文章上，知识库能
复利扩张；一个 50 篇文章、月成本 $15,000 的库等于 $300/篇——这时指标
在提醒你要扩大规模或停手。

## 案例走读

假设一家中型 B2B SaaS 知识库团队月成本 $15,000、每月分流 1,750 张工
单、按 $24/张混合成本计算、知识库总文章数 500 篇、内部目标 500% ROI：

1. `毛节省` = 1,750 × $24 = **$42,000/月**
2. `净节省` = $42,000 − $15,000 = **$27,000/月**
3. `ROI` = ($27,000 ÷ $15,000) × 100 = **180%** → 🟡 **Good** 等级
4. `每篇文章成本` = $15,000 ÷ 500 = **$30.00/篇/月**（远低于 $50）
5. 要达到 500% ROI 目标，需把月分流提升至 **3,750 张**（+2,000 张）
   或把知识库月成本砍到 **$7,000 以下**
6. 要达到 🟢 Excellent（400% 且每篇 ≤$50，第二条已满足），需把月分流
   提升至 3,125 张

杠杆顺序很关键：抬高分流（靠 K-1 覆盖率）能复利；砍团队成本是一次性
收益。搭配**自助分流率**（P12-5）一起看。
