## 这个计算器衡量什么

课程定价是独立创作者做出的最高杠杆决策——同样 50 单/月，$50 的
单价差就是年化 $30,000 的收入差，而绝大多数创作者在首发时定得过
低、之后再也涨不回来。本计算器求解覆盖平台抽成后**仍能拿到目标月
收入的最优价格点**，并附上创作者经济视角（**每创作小时收入**）、
平台费后的毛利润率、以及自学版 vs 训练营版的盈亏平衡。它面向在
Teachable、Podia、Gumroad、Thinkific、Kajabi 或自建 WordPress + Stripe
上卖课的独立创作者，不适合靠付费投放大规模获客的运营型卖家。

## 计算方法

定价顾问常用的「最优价格反推」：

```
抽成乘数        = 1 ÷（1 − 平台抽成 ÷ 100）
盈亏平衡价      = 目标月收入 ÷ 月单数
最优价格        = 盈亏平衡价 × 抽成乘数
毛收入          = 最优价格 × 月单数
平台抽走        = 毛收入 ×（平台抽成 ÷ 100）
净收入          = 毛收入 − 平台抽走
每创作小时收入  =（净收入 × 12）÷（创作工时 × 12）
LTV             = 最优价格 × 1.5   // 50% 追加销售转化率
训练营溢价      = 最优价格 × 3.5   // 训练营比自学版贵 3.5 倍
```

| 变量              | 含义                                            |
| ----------------- | ----------------------------------------------- |
| `目标月收入`      | 你想每月净落袋的金额                            |
| `月单数`          | 首发 → 稳态的月销量（现实估算）                 |
| `平台抽成`        | 平台抽走的百分比（Teachable 5%、Gumroad 10%、Udemy 3-63%） |
| `创作工时`        | 课程一次性制作工时（基线 40 小时）              |
| `抽成乘数`        | 反推抽成，确保你拿回目标净额                    |

**假设。** 模型假设订单在月内均匀分布——单次发布周通常会集中全年
50-70% 的收入到 7-14 天。平台费率按固定值处理；不另叠加支付通道
费率（Stripe 2.9% + $0.30）。1.5x LTV 乘数假设下游追加销售（训练营、
教练、模板包）有 50% 转化；如果你的追加销售转化率低于 30%，手动降
低该乘数。

## 局限性 / 何时不适用

本计算器建模的是**单课程、稳态运营**。如果你同时卖多门课、会员、
或捆绑包，请分别建模每个 SKU 然后汇总收入。发布期定价扰动（早鸟
折扣、训练营奖励、倒计时）不在模型内——「Launch Revenue」段假设
平均 30% 的发布折扣。每创作小时指标把所有创作工时视为同等价值，
但前 20 小时（调研、大纲、脚本）和后 20 小时（后期制作、打磨）价值
差异很大——把它当方向锚点，不要当时间追踪输入。币种固定 USD，国际
创作者输入前先把目标收入换算成 USD。

## 案例走读

一位创作者想从新课程净赚 $5,000/月，预计月销 50 单（2,500 订阅邮箱
× 2% 转化），挂在 Teachable 上平台抽 10%：

1. `盈亏平衡价` = $5,000 ÷ 50 = **$100/学员**
2. `抽成乘数` = 1 ÷（1 − 0.10） = **1.111**
3. `最优价格` = $100 × 1.111 = **$111.11/学员**
4. `毛收入` = $111.11 × 50 = **$5,556/月**
5. `平台抽走` = $5,556 × 10% = **$556/月**
6. `净收入` = $5,556 − $556 = **$5,000/月** = **$60,000/年**
7. `每创作小时收入` = $60,000 ÷（40 × 12） = **$125/创作小时**

定价阶梯段还给出 9 个价位（$29、$49、$97、$147、$197、$297、$497、
$697、$997）的月/年净收入：定到 $297 同样 50 单净赚 $13,365/月，
叠加 30% 转化的训练营 tier 可解锁额外 $70,000/年。搭配
**Email List Revenue Calculator** 给发布期需要的邮箱量建模，搭配
**Project Profitability Calculator** 判断创作工时本身值不值你的时间。
