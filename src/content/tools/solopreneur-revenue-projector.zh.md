## 这个计算器衡量什么

SaaS 财务预测器把订阅业务向前推 6/12/24 个月，回答经营者真正会问的五个问题：*MRR 落到哪？什么时候到盈亏平衡？跑道还有多久？CAC 回收要几个月？哪一两个杠杆最能撬动数字？* 它把标准 SaaS **净增长复利**模型和 **Burn Multiple、Rule of 40、LTV:CAC、CAC 回收期**这四个 Bessemer 和 OpenView 视为投资基准的比率合在一起。这是一个"我的 SaaS 健康吗"的单页仪表盘。

## 计算方法

我们使用的 v3 标准公式：

```
月度净增长率   = (毛增长率 − 月流失率) ÷ 100
期末 MRR       = 当前 MRR × (1 + 月度净增长率)^月数
总营收         = Σ  当前 MRR × (1 + 月度净增长率)^m   m=1..月数
年化净增长率   = (1 + 月度净增长率)^12 − 1
跑道           = 现金 ÷ (月支出 − 当前 MRR)   （烧钱时）
盈亏平衡月数   = ⌈log(月支出 ÷ 当前 MRR) ÷ log(1 + 月度净增长率)⌉
CAC 回收期     = CAC ÷ (ARPU × (1 − 流失率÷100))
LTV            = ARPU ÷ (流失率÷100)
LTV:CAC        = LTV ÷ CAC
Rule of 40     = 月度净增长率×100 + 利润率
```

| 变量           | 含义                                       |
| -------------- | ------------------------------------------ |
| `当前 MRR`     | 当下的月经常性收入                         |
| `毛增长率`     | 月新签 + 扩展 MRR 占当前 MRR 的百分比      |
| `月流失率`     | 月度取消 + 缩减占 MRR 的百分比             |
| `月支出`       | 月运营支出总额（毛烧钱）                   |
| `现金`         | 经营账户的活期余额                         |
| `ARPU`         | 人均月收入                                 |
| `自定义增长率` | 可选"如果我长得更慢/更快"假设              |
| `CAC`          | 客户获取成本（混合、每个新客户）           |
| `月数`         | 预测期 6 / 12 / 24                         |

**假设。** 净增长按月对当前 MRR 复利——不会建模产品上线、招聘爬坡或中途调价。利润率基于今天支出计算，不是前瞻成本曲线。对一个没有大幅人事变动的独立创业者来说这是紧致近似；对一个计划半年内招 5 个人的融资团队，请用招完人后的成本基数重新跑模型。

## 局限性 / 何时不适用

这个仪表盘假设**单一订阅收入流的订阅业务**。如果你有重要的服务或硬件业务线，请单独叠一层（或扩展模型）——70/30 SaaS/服务的混合业务和纯 SaaS 预测表现差异巨大。复利公式还会过度平滑真实波动：实际 MRR 月度会上下震荡，3 个月的投放断档就能让净增长突然掉 5pp。请用**自定义增长率**场景提前模拟放缓，而不是事后救火。

## 案例走读

一家 B2B SaaS 当前 MRR $5,000，月毛增长 8%，月流失 3%，月支出 $3,000，现金 $60,000，ARPU $25，CAC $200，预测 12 个月：

1. `月度净增长率` = (8 − 3) ÷ 100 = **+5%/月**（复利）
2. `期末 MRR` = $5,000 × 1.05¹² = **$8,979/月**（年增 80%）
3. `总营收` = 12 个月求和 ≈ **$80,000**
4. `月烧钱` = 3,000 − 5,000 = **−$2,000/月（盈利）**——已经到达盈亏平衡
5. `跑道` = ∞（盈利），但零收入跑道 = 60,000 ÷ 3,000 = **20 个月**作为安全垫
6. `CAC 回收期` = 200 ÷ (25 × 0.97) = **8.2 个月**（🟢 低于 12 个月基准）
7. `LTV:CAC` = (25 ÷ 0.03) ÷ 200 = **4.2×**（🟢 高于 3× 投资人门槛）
8. `Rule of 40` = 5 + 0 = **5%**（🔴 低于 20%）——现在盈利，但增长会放缓；应再投入一条获客渠道
