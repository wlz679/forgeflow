## 这个计算器衡量什么

Coupon Attribution（优惠券归因）计算器通过**自损率**（cannibalization
——会原价下单却被优惠券截胡的那部分订单）调整毛收入，衡量一次优
惠券活动的**真实 ROI**。粗略的"毛收入 × 优惠面值"框架会普遍把活动
价值高估 2–3 倍；这个工具呈现的是真正的增量净收入，以及让优惠券
"刚好打平"的自损率门槛。在审批新券码、复盘活动后报告、或向高管辩
护"无折扣"定价立场时使用。

## 计算方法

我们使用的 v3 标准公式（Shopify / Klaviyo 标准）：

```
毛优惠券收入     = 基线收入 × (核销率 / 100) × AOV
优惠券成本       = 基线收入 × (核销率 / 100) × 优惠面值
增量收入        = 毛优惠券收入 × (1 − 自损率 / 100)
自损损失        = 毛优惠券收入 − 增量收入
净收入增长      = 增量收入 − 优惠券成本
真实 ROI %     = (净收入增长 / 优惠券成本) × 100
盈亏平衡自损率 = 1 − (优惠券成本 / 毛优惠券收入)
```

| 变量        | 含义                                                              |
| ----------- | ----------------------------------------------------------------- |
| `优惠面值`  | 优惠券面值（如满 80 减 20）                                       |
| `核销率`    | 基线客户中实际用了券的百分比（典型 5–15%）                        |
| `客单价`    | 用券时的客单价                                                    |
| `基线收入`  | 活动前的基线收入（用来估算核销量）                                |
| `自损率`    | 本来会原价下单、却用券的那部分比例（无 A/B 测试时取 30%）         |

健康分带（真实 ROI）：🟢 ≥ 100% · 🟡 0–100% · 🔴 < 0%（3 段制，见说明）。

**3 段制说明**：真实优惠券 ROI 在 100% 处有结构性盈亏分界（赚钱↔
亏本边界）。硬塞一个 🟠 警示带会强制一个没有业务意义的任意中点——
见 CLAUDE.md "hard-breakpoint exemption" 记录的豁免条款。

这些分级来自：Shopify 优惠券分析文档、Klaviyo 优惠券营收归因指南，以及 RetailMeNot 年度优惠券使用报告（2023 年 88% 消费者购物时使用过优惠券）。

## 局限性 / 何时不适用

`自损率` 是最关键的杠杆，也是最难测准的一个。没跑过 A/B 测试时
行业默认是 30%（Shopify / Klaviyo 启发值）。如果手头有地理 holdout
测试或随机券资格实验的数据，请用实测值替换——这里 10 pp 的误差就
能把结论从 🟢 翻到 🔴。模型还假设用券 / 不用券订单的**客单价相同**；
如果用券吸引的是客单价更低的"捡漏党"，真实 ROI 会比计算器更难看。

## 假设与边界

- 归因假设优惠券代码是购买前的最后接触 — 首次接触归因可能会在自然和优惠券驱动之间转移约 10-20% 转化。
- 边际成本计算包含按兑换率调整的分发成本（邮件/短信发送 × 投递成本），不只算面值折扣。
- 不区分新老客的优惠券驱动与自然转化 — 需要细分分析请配合 LTV-by-channel 计算器。

## 常见误区

- 把所有优惠券用户都当作净新增 — 60-70% 优惠券用户本来就会购买；永远报告增量提升，而不是毛转化。
- 全站通用折扣而非细分人群优惠 — 全站 8 折比定向给未转化用户 8 折更伤毛利；衡量细分 ROI。
- 忽略优惠券叠加和代码泄露 — 联盟/达人代码可能与公开代码叠加，折扣翻倍；定期审计异常兑换模式。

## 案例走读

某 DTC 家居品牌在 $50,000 月基线收入上发 "SPRING20"（$20 减），
核销率 10%，客单价 80 元，自损率估计 30%：

1. `毛优惠券收入` = 50,000 × 0.10 × 80 = **400,000 元**
2. `优惠券成本`   = 50,000 × 0.10 × 20 = **100,000 元**
3. `增量收入`    = 400,000 × (1 − 0.30) = **280,000 元**
4. `净收入增长`  = 280,000 − 100,000 = **180,000 元**
5. `真实 ROI %` = (180,000 / 100,000) × 100 = **180%**（🟢）
6. `盈亏平衡自损率` = 1 − (100,000 / 400,000) = **75%**——自损率
   控制在 75% 以下都还有正收益（估算 30%，安全垫 45 pp）

Dashboard 的 What-If 建模："如果自损率是 60%（悲观估计），真实
ROI 跌到 (400,000 × 0.40 − 100,000) / 100,000 = 60%（🟡 脆弱），
还是正但已经很勉强。" 验证券获取客户的复购率与正价客户一致时，
请搭配 **Cohort Retention（同期群留存）** 工具。
