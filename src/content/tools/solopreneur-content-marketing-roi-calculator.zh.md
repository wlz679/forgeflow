## 这个计算器衡量什么

Content Marketing ROI（内容营销 ROI）计算器建模 SEO 和内容的**延迟
回报**经济性：先有一段爬坡期（months-to-rank）贡献为负，进入稳态期
后自然流量开始复利。它会算出 12 个月总利润、稳态月收入、盈亏平衡转
化率，并把归因模型（首次点击 / 最后点击 / 线性）作为一个显式开关。
在为内容团队预算辩护、应对付费渠道支持者时使用，或用来建模一个新
内容垂直的经济性。

## 计算方法

我们使用的 v3 标准公式：

```
月收入           = 流量 × (CR / 100) × AOV
归因乘数         = 首次点击 / 最后点击 = 1.0
                 线性                = 0.7
12 个月总利润   = Σ 月净收入 × 归因乘数
                 区间 [爬坡期, 爬坡期 + 12]
盈亏平衡 CR     = 月内容成本 / (峰值流量 × AOV × 归因乘数)
```

| 变量              | 含义                                                              |
| ----------------- | ----------------------------------------------------------------- |
| `月篇数`          | 每月发布的新内容篇数（博客、指南等）                              |
| `爬坡月数`        | 平均到 Google 第一页排名的耗时（SEO 爬坡期）                      |
| `月峰值流量`      | 内容成熟后稳态下的月自然访客数                                    |
| `转化率`          | 自然访客中转化的百分比（注册、购买等）                            |
| `AOV`             | 客单价（SaaS 场景下取每访客 LTV）                                 |
| `月内容成本`      | 写手 + 编辑 + 设计 + CMS 平台分摊（每月固定）                     |
| `归因模型`        | `first-touch` / `last-touch`（拿 100% 功劳）或 `linear`（70%）   |

健康分带（转化率）：🟢 ≥ 3% · 🟡 1–3% · 🟠 0.3–1% · 🔴 < 0.3%。

## 局限性 / 何时不适用

模型假设**单一爬坡窗口**接稳态流量。真实 SEO 是波动的：一篇爆款
可能 2 周内把流量撑到 5 倍，然后衰减。另外，归因是对单一数值的
**乘数**——如果你的内容与付费搜索并行投放，最后点击会低估内容
对认知阶段转化的贡献。线性归因 0.7 这个乘数是 Wistia / ChartMogul
混合归因研究里的启发值；要拿真正的多点归因收入，请接入你的 MTA 工具。

## 案例走读

假设某 SaaS 内容团队每月发 8 篇文章，6 个月 SEO 爬坡后期望峰值
自然流量 5,000 访客/月，CR 2%，AOV 80 元，月内容成本 2,000 元
（写手 + 设计），最后点击归因：

1. `月收入（稳态）` = 5,000 × 0.02 × 80 = **8,000 元**
2. `月净收入`       = 8,000 − 2,000 = **6,000 元**
3. **第 1–6 月（爬坡）**：−2,000 元/月 = **累计 −12,000 元**
4. **第 7–12 月（稳态）**：+6,000 元/月 = **累计 +36,000 元**
5. **12 个月总利润** = −12,000 + 36,000 = **24,000 元**（🟢）
6. `盈亏平衡 CR` = 2,000 / (5,000 × 80 × 1.0) = **0.5%**（模型给的 2%
   比盈亏平衡高 4 倍，足够安全垫）

Dashboard 的 What-If 建模："如果 CR 从 2% 提到 3%，12 个月利润
从 24,000 涨到 48,000，而且不用多花一分钱。" 验证自然获取的用户
留存与付费用户一致时，请搭配 **Cohort Retention（同期群留存）**
工具。
