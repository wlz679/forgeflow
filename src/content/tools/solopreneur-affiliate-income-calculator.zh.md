## 这个计算器衡量什么

联盟营销（affiliate）收入是访客点击你的追踪推荐链接并完成指定动作
（通常是购买）后你拿到的佣金。本计算器把你的月流量、点击转化率、
平均佣金转成每一个联盟合伙人最关心的几个核心数字：月收入、年收入、
**Earnings Per Click（EPC）**、每千访客收益、扣除运营成本后的净利润率、
以及覆盖成本的盈亏平衡流量。它面向内容站长、垂直站点运营者、用
newsletter 做变现的创作者，常见联盟涵盖 Amazon Associates、SaaS
合作伙伴网络、以及直签品牌合作。

## 计算方法

联盟网络通用的漏斗模型：

```
月转化数       = 月流量 ×（转化率 ÷ 100）
月收入         = 月转化数 × 平均佣金
年收入         = 月收入 × 12
单访客收益     = 月收入 ÷ 月流量
每千访客收益   = 单访客收益 × 1,000
月净利润       = 月收入 − 月成本
盈亏平衡流量   = 月成本 ÷ 单访客收益
```

| 变量              | 含义                                            |
| ----------------- | ----------------------------------------------- |
| `月流量`          | 每月看到联盟链接的唯一访客数                    |
| `转化率`          | 完成联盟动作的访客占比（行业 1-3%）             |
| `平均佣金`        | 每次转化的平均分成（一次性或循环）              |
| `月成本`          | 主机、工具、内容制作、付费投放                  |
| `单访客收益（EPC）`| 关键效率指标——单访客能带来多少收入            |

**假设。** 收入按 100% 佣金计算（Amazon、ShareASale、CJ 已经在结算
前扣过网络分成，所以你输入的应该是实际到手佣金）。模型假设流量全
年稳定——季节性、节假日、产品发布爆量都不在考虑范围。循环分成项目
（SaaS 伙伴网络）的 cohort 累积会让 12 个月乘数逐年走高，本计算器
把循环尾巴按线性年化处理。

## 局限性 / 何时不适用

本计算器假设单一垂类和统一佣金。如果你同时跑多个分成结构差异很大
的项目（如 Amazon 1-4% 一次性 vs SaaS 20-30% 循环），单一「平均佣金」
输入会退化为加权平均，颗粒度丢失。它也**不是税务工具**：联盟佣金在
大多数司法管辖区属于自雇收入，要交所得税 + 自雇税（美国约 15.3%）。
成本输入不包含退款率、拒付、佣金追回——联盟网络会因订单退款回滚
佣金，实际年化收入通常比毛收入低 5-15%。

## 案例走读

一个专注效率软件测评的垂直站每月 50,000 访客，联盟链接转化率 2%，
平均每单佣金 $50（Amazon + AppSumo + SaaS 循环混合），月度运营成本
$200（主机 + 内容）：

1. `月转化数` = 50,000 × 2% = **1,000 单**
2. `月收入` = 1,000 × $50 = **$50,000/月**
3. `年收入` = $50,000 × 12 = **$600,000/年**
4. `单访客收益（EPC）` = $50,000 ÷ 50,000 = **$1.00**（顶级四分位）
5. `月净利润` = $50,000 − $200 = **$49,800/月**，利润率 99.6%
6. `盈亏平衡流量` = $200 ÷ $1.00 = **200 访客/月**——远低于当前流量

模型显示，按当前转化率，要净赚 $5,000/月大约需要 5,200 访客/月。
本工具的「Scale Projection」段把这条路径延伸到 9 个流量层级
（1K 到 1M 访客/月），让你看到 SEO 和内容产出复利后的样子。搭配
**Email List Revenue Calculator** 还能建模「从租流量变成自有受众」
后的差别。
