## 这个计算器衡量什么

供应商评分卡把四个难以直接比较的供应商 KPI 压缩成一个加权总分与字母
等级（A/B/C/D）。它是运营者回答「这家供应商该续约、双供应商、还是
换掉？」的工具——建立在 SCOR 模型「采购」支柱之上，对应的四个维度
也是 ISO 9001 采购审计的标配：**准时交付率、缺陷率、前置期波动、成本
波动**。综合分让 10 家供应商可以并排对比，不用再做苹果对橘子的折算。

## 计算方法

v3 标准公式如下：

```
准时分    = clamp(准时率%,                       0, 100)
缺陷分    = clamp(100 − 缺陷率% × 10,             0, 100)
前置期分  = clamp(100 − 前置期波动天数 × 5,       0, 100)
成本分    = clamp(100 − |成本波动%| × 2,          0, 100)

综合分    = Σ（子分_i × 权重_i）
等级      = A（≥90）· B（80–90）· C（70–80）· D（<70）
```

| 变量           | 含义                                                                  |
| -------------- | --------------------------------------------------------------------- |
| `准时率`       | 按约定日期交付的订单占比                                              |
| `缺陷率`       | 有瑕疵或被退货的订单占比（1% = 扣 10 分）                             |
| `前置期波动`   | 实际前置期相对承诺值的标准差（1 天 = 扣 5 分）                        |
| `成本波动`     | 实际成本相对报价的偏离百分比（1% = 扣 2 分）                          |
| `权重预设`     | `balanced`（40/30/15/15）· `quality`（25/50/15/10）· `speed`（50/20/25/5）· `cost`（20/20/10/50）。 |

健康度分档对齐字母等级阈值：🟢 ≥ 90（A）· 🟡 80–90（B）· 🟠 70–80（C）·
🔴 < 70（D）。四个子分公式遵循 SCOR 度量惯例与 ISO 9001 §8.4 采购条款。

## 局限性 / 何时不适用

四维模型假设你能量化每个维度。**没有采购订单跟踪的中小运营者**（通常
每年与某供应商的交易 < 50 单）样本量不足，无法算出有意义的方差——建议
用 12 个月滚动窗口，或对低交易量供应商直接跳过评分卡。综合分也是单维度
的：**如果某战略供应商的成本波动大但准时率满分、且替代方更慢，可能值
得忍受**。在真正决策换 / 留时，请把评分与定性笔记配套使用。

## 案例走读

一家 DTC 品牌盘点某关键供应商：准时 88%、缺陷 2.5%、前置期波动 3 天、
成本波动 5%，使用 balanced 权重：

1. `准时分` = min(100, 88) = **88**
2. `缺陷分` = clamp(100 − 2.5 × 10) = **75**
3. `前置期分` = clamp(100 − 3 × 5) = **85**
4. `成本分` = clamp(100 − |5| × 2) = **90**
5. `综合分` = 88 × 0.40 + 75 × 0.30 + 85 × 0.15 + 90 × 0.15
   = 35.2 + 22.5 + 12.75 + 13.5 = **84.0** → 等级 **B** → 🟡 持续观察。
6. What-If：缺陷率降至 0.5% → 缺陷分跃至 95，综合分升至 90.0 → 等级
   **A**。**+6 综合分**通常足以换取一份更长约期的合同。
