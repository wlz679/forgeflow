## 这个计算器衡量什么

自由职业和自雇收入的课税方式与 W-2 工薪不同：没有雇主代扣联邦所得税、
社保、医保或州税，这些都要靠你每个季度预估申报来缴。这个计算器横跨
五个国家（美国、英国、加拿大、澳大利亚、德国）估算年度总税额，把它
拆成季度税款和每月预留金额，并给出税后月度到手收入。它同时呈现
自雇 vs W-2 的临界点对比，并跑出 what-if 场景：退休账户供款上限、
报税身份切换、S-Corp 选举、可抵扣营业支出。

## 计算方法

我们使用的 v3 标准公式：

```
应税收入       = 总收入 − 营业支出 − min(退休供款, 25% × 总收入)
美国 联邦税     = 应税收入 × 0.30          （合并有效税率）
美国 州税       = 应税收入 × (stateRate / 100)  （仅美国）
美国 自雇税     = 应税收入 × 0.153 × 0.9235     （对 92.35% 净额征 15.3%）
英国            = 应税收入 × 0.25
加拿大          = 应税收入 × 0.26
澳大利亚        = 应税收入 × 0.275
德国            = 应税收入 × 0.35
总税           = 联邦税 + 州税 + 自雇税
有效税率       = 总税 / 总收入 × 100
季度税         = 总税 / 4
每月预留       = 总税 / 12
月度到手       = (总收入 − 总税) / 12
```

| 变量          | 含义                                                                  |
| ------------- | --------------------------------------------------------------------- |
| `总收入`      | 任何扣除之前的年度自由职业收入                                        |
| `营业支出`    | 合法且必要的支出（家庭办公、软件、差旅）                              |
| `退休供款`    | SEP-IRA / Solo 401k 供款，上限为净自雇收入的 25%（约 $66K）           |
| `报税身份`    | `single`（标准扣除 $14,600）、`married`（$29,200）、`hoh`（$21,900） |
| `州税率`      | 州 / 地方所得税百分比 — 仅对美国纳税人适用                            |
| `国家`        | `us` / `uk` / `canada` / `australia` / `germany` 之一                 |

自雇 vs W-2 临界点告警在 $80,000 总收入时触发：此时额外的自雇税加上
自付福利（医保、退休、工资管理）的成本开始超过节税收益。标准扣除金额
按 IRS 2026 年公布数值。

## 局限性 / 何时不适用

这个计算器对每个国家用单一合并有效税率，而不是真实申报使用的累进
税率表。它没有建模资本利得、股息收入，或 QBI（第 199A 条）20% 穿透
扣除 —— 这条扣除通常让美国自雇税再降 20%。各州 / 省的具体细则
（加州 SDI、纽约 MCTMT、魁北克 QPP、德国 Gewerbesteuer 工商税）也没
处理。这个工具用于月度现金流规划和季度预留决策；最终申报请用
TurboTax、H&R Block 或找 CPA。如果你有跨州收入、K-1 合伙企业收入
或出租房收入，合并方式会高估或低估实际税负 5-15%。

## 案例走读

美国单身自由职业者，总收入 $100,000，营业支出 $15,000，向 SEP-IRA
供款 $10,000：

1. `退休扣除` = min($10,000, 25% × $100,000) = **$10,000**
2. `应税收入` = $100,000 − $15,000 − $10,000 = **$75,000**（引擎内部还会再扣 $14,600 标准扣除再算税）
3. `联邦税` = $75,000 × 0.30 = **$22,500**
4. `州税`（5%）= $75,000 × 0.05 = **$3,750**
5. `自雇税` = $75,000 × 0.153 × 0.9235 = **$10,597**
6. `总税` = $22,500 + $3,750 + $10,597 = **$36,847**  →  `有效税率` = **36.8%**
7. `季度税` = $36,847 / 4 = **$9,211.79**（4/15、6/15、9/15、1/15 截止）
8. `每月预留` = $36,847 / 12 = **$3,070.60**，`月度到手` = **$5,262.74/月**

搭配 **Time Value Calculator** 看月度到手的时薪，搭配 **Compound
Interest Calculator** 测算每年能投入 SEP-IRA 或 Solo 401k 的复利效果。
What-If 区还显示：净收入超过 $60-80K 后选举 S-Corp 可省下约 $5,299/yr
自雇税。
