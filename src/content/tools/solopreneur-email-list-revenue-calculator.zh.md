## 这个计算器衡量什么

邮件列表收入是「**每位订阅者每年带来多少美元**」这个数字——这是每
一个 newsletter 运营者、课程创作者、电商创始人都最在意的指标。本
计算器把你的订阅数、打开率、点击率、转化率、客单价、发送频率四步
漏斗转成四个能告诉你这份列表是真业务还是虚荣指标的数字：**单次发
送收入**、**月收入**、**年收入**、**$/订阅者/年**。它还会按现实的
净增长速率预测列表成长，并告诉你打到 $5K、$50K、$100K/年需要多少
活跃订阅者。它面向在 ConvertKit、beehiiv、Substack、Mailchimp、Kit
上运营的 newsletter 主，以及把邮件作为主要分发渠道的创作者。

## 计算方法

所有邮件营销平台后台都跟踪的四步漏斗：

```
打开数         = 订阅数 ×（打开率 ÷ 100）
点击数         = 打开数 ×（点击率 ÷ 100）
转化数         = 点击数 ×（转化率 ÷ 100）
单次发送收入   = 转化数 × 客单价
月收入         = 单次发送收入 × 月发送数
年收入         = 月收入 × 12
每订阅者收入   = 年收入 ÷ 订阅数
净增长率       = 10% − 月退订率   // 10% 获取基线
```

| 变量           | 含义                                            |
| -------------- | ----------------------------------------------- |
| `订阅数`       | 列表总规模（活跃 + 沉睡）                       |
| `打开率`       | 单次发送的打开占比（行业 20-30%）               |
| `点击率`       | 打开者中点击任何链接的占比（典型 2-5%）         |
| `转化率`       | 点击者中购买的比例（典型 1-3%）                 |
| `客单价`       | 邮件流量带来的平均订单金额                      |
| `月发送数`     | 发送节奏（行业 2-8，甜点 4）                    |
| `退订率`       | 月度流失（典型 0.3-1%）                         |

**假设。** 漏斗指标按独立步骤处理（打开 → 点击 → 转化），这对批量
发送是现实的，但自动化序列里每一步都会推高下一步；模型低估了序列
效果。10% 净月增长基线假设有活跃的 lead magnet 和稳定更新；沉睡列
表增长慢得多。收入按毛收入计算——不扣除 ESP 费用（ConvertKit、
beehiiv）或支付通道费（Stripe 2.9% + $0.30），这些加起来能到 4-8%。

## 局限性 / 何时不适用

本计算器建模的是**对全量列表的批量发送**。它不适合赞助位 / 收入
预测（一次赞助按 CPM 固定结算，与点击无关）、lead magnet 漏斗建模
（需要逐步独立视角）、B2B 邮件序列（每一步目标和报价都不同）。它
也假设单一变现模型——大多数列表是产品、联盟、赞助的混合，请把本
工具用在「产品」那一块。对于分群列表，按分群分别跑一次（或按批量
子群分别跑），整体 $/订阅者/年应该按权重汇总。国际创作者输入前先
把客单价和目标收入换算成同一币种。

## 案例走读

一份 10,000 订阅者的 newsletter，跑在 ConvertKit 上，打开率 25%
（活跃创作者列表的行业均值），点击率 5%（健康），点击到购买转化
2%，客单价 $50，每月发 4 封，月退订率 0.5%：

1. `打开数` = 10,000 × 25% = **2,500 打开/次**
2. `点击数` = 2,500 × 5% = **125 点击/次**
3. `转化数` = 125 × 2% = **2.5 单/次**
4. `单次发送收入` = 2.5 × $50 = **$125/次**
5. `月收入` = $125 × 4 = **$500/月**
6. `年收入` = $500 × 12 = **$6,000/年**
7. `每订阅者收入` = $6,000 ÷ 10,000 = **$0.60/订阅者/年**（低于 $1-2 基线）

工具会标记这条列表低于行业基准，并显示打到 $5K/年需要约 8,333
活跃订阅、$50K/年需要约 83,333。按 9.5% 净月增长（10% 获取 − 0.5%
流失）复利 12 个月后列表达到 29,715 人，按同样的漏斗指标预测
**$17,829/年**。要达到顶层四分位的 $/订阅者/年（$5-20），按兴趣和
历史购买分群——分群发送通常比批量广播强 3-10 倍。搭配 **Affiliate
Income Calculator**，如果你在每封邮件里也放联盟推荐位可以一起建模。
