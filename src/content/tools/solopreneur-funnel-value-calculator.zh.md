## 这个计算器衡量什么

Funnel Value（漏斗价值）计算器走标准的 4 段电商 / 潜客漏斗——曝光 →
点击 → 潜客 → 成交——并同时回答两个问题："这个漏斗每月到底产出多少
收入？"以及"哪一段是最大的漏水点？"它会输出整体转化率、每段流失、
预期收入（毛利和净利），以及任一段优化后的 What-If 预测。当你怀疑
CTR 这类虚荣指标掩盖了漏斗真问题时，就该用它。

## 计算方法

我们使用的 v3 标准公式：

```
点击数       = 曝光数 × (CTR / 100)
潜客数       = 点击数 × (潜客率 / 100)
成交数       = 潜客数 × (成交率 / 100)
整体转化率   = 成交数 / 曝光数 × 100
毛收入      = 成交数 × AOV
净收入      = 毛收入 × (毛利率 / 100)
最大漏点    = 用户绝对流失最大的那一段
```

| 变量      | 含义                                                              |
| --------- | ----------------------------------------------------------------- |
| `曝光数`  | 漏斗顶的量（广告曝光、自然会话等）                                |
| `CTR`     | 曝光变成点击的百分比                                              |
| `潜客率`  | 点击者中变成已识别潜客（邮箱、注册、加购）的百分比                |
| `成交率`  | 潜客中变成付费客户的百分比                                        |
| `AOV`     | 成交段的客单价                                                    |
| `毛利率`  | 每单的利润率（1 − COGS / 履约成本）                              |

健康分带（整体转化率）：🟢 ≥ 5% · 🟡 1–5% · 🟠 0.1–1% · 🔴 < 0.1%。

工具会标记**最大漏点**（用户数绝对流失最大的那一段）——通常最高 ROI
的优化工作就藏在那里。

## 局限性 / 何时不适用

漏斗价值假设是**线性、顺序**的漏斗。如果你的真实流程有回路（用户返回
上一段，例如 直播 → 邮件培育 → 销售电话），这个模型会少算。
另外"最大漏点"对**绝对量**敏感，不是相对率——100 万曝光掉 1% 远比
100 个潜客掉 50% 严重，引擎会正确标记前者。多路径漏斗请改用行为分
析工具（Mixpanel、Amplitude），不要用静态计算器。

## 案例走读

某 DTC 服饰店的月度漏斗：100,000 曝光，CTR 2.5%，潜客率（注册）15%，
成交率 5%，AOV 80 元，毛利率 70%：

1. `点击数` = 100,000 × 0.025 = **2,500**
2. `潜客数` = 2,500 × 0.15   = **375**
3. `成交数` = 375 × 0.05     = **18.75 → 19**
4. `整体转化率` = 19 / 100,000 × 100 = **0.019%**（🔴 危险带——冷流量付费投放的常态）
5. `毛收入` = 19 × 80 = **1,520 元**  ·  `净收入` = **1,064 元**

最大漏点出现在 **曝光 → 点击**（流失 97,500），所以 Dashboard 的
What-If 建模："如果 CTR 从 2.5% 提到 3.5%（+40%），收入会涨到
2,128 元左右——而且**不用多花一分钱流量费**。" 扩量前请搭配
**Cohort Retention（同期群留存）** 工具，验证你**确实**抓到的潜客
下游会转化。
