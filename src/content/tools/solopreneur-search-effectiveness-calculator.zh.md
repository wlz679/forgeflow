## 这个计算器衡量什么

搜索有效性通过两个指标的复合来衡量知识库内嵌搜索对用户的服务质量——
点击率（产生点击的搜索占比）与无结果率（返回零结果的搜索占比）。一个
知识库覆盖率即使达到 100%，如果搜索栏无法命中对的文章，用户依然会失
望。Algolia 的研究显示，调校欠佳的知识库搜索中，30-40% 的点击之后会
出现"弹簧跳"——用户点开一篇文章后发现不对，立刻返回搜索栏再找一遍。
这种隐形失败模式在覆盖率指标里完全看不出来，但在这个复合指标里会清
清楚楚地暴露。

## 计算方法

```
点击率    = 产生点击的搜索数 ÷ 搜索总数
无结果率  = 无结果搜索数 ÷ 搜索总数
放弃/停留 = max(0, 总数 − 点击数 − 无结果数)
```

| 变量            | 含义                                       |
| --------------- | ------------------------------------------ |
| `搜索总数`      | 测量月内所有知识库内嵌搜索事件             |
| `产生点击的搜索` | 用户点击了至少一条结果的搜索数            |
| `无结果搜索`    | 返回零匹配的搜索数                         |
| `行业基准`      | B2B SaaS / Consumer——仅作信息提示         |

健康等级采用复合 AND 逻辑（两个条件同时满足）：
🟢 Excellent（点击率 ≥85% 且无结果率 ≤5%）· 🟡 Good（点击率 70-85%
且无结果率 ≤10%）· 🟠 Warning（点击率 55-70% 且无结果率 ≤20%）；
🔴 Critical（任一条件不达标）。

## 局限性 / 何时不适用

搜索效用在搜索量不足时几乎无意义——月搜索次数 <1,000 时，无结果率每
周波动 5-10pp，健康等级会反复横跳。另外，B2B SaaS 与 Consumer 知识库
的预期差距极大：Consumer 用户搜索短尾词、容忍更高无结果率；B2B 用户
搜索长尾词、带着明确任务而来，无结果容忍度更低。行业基准选项仅作
参考，请按自家用户类型校准目标。搜索有效性假设你的知识库客户端在日
志搜索事件——如果用的是服务端渲染又未捕获事件，请改用 Algolia / Coveo
或者帮助台自带的分析面板导出数据。

## 案例走读

假设一家中型 B2B SaaS 月内知识库搜索 12,000 次，其中 9,000 次产生
点击，960 次无结果：

1. `点击率` = 9,000 ÷ 12,000 = **75.0%** · `无结果率` = 960 ÷ 12,000 = **8.0%**
2. 🟡 **Good** 等级两个条件同时满足（点击率 70-85% 且无结果率 ≤10%）
3. `放弃/停留` = 12,000 − 9,000 − 960 = **2,040** 次悬停或离开
4. 要达到 🟢 Excellent（点击率 ≥85% 且无结果率 ≤5%），需新增 **1,200 次**
   点击 或 减少 **360 次** 无结果搜索
5. 按 ~50% 点击-转-工单的预防率，缩小点击率差距每月可预防约 **600 张**
   工单被创建

搭配**知识库覆盖率**（K-1）：无结果率高但 K-1 覆盖率也高，缺口在同义
词/分类法（一周可修）；如果 K-1 覆盖率也低，则缺口在内容本身（需要
新写文章）。
