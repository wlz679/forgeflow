## 这个计算器衡量什么

单位经济（Unit Economics）把 SaaS 业务拆解到「每位客户」的盈利机制：每位客户产生多少收入（含扩展增购）、服务他需要花多少钱、他会停留多久。它回答创始人最核心的问题：*每位客户自身是否盈利？* 如果单位经济为正，你就有了可持续生意的基础；如果为负，规模化只会加速现金燃烧。在决定花多少钱做增长之前先用这个计算器 —— 它告诉你 CAC 的上限、回收期的下限。

## 计算方法

v3 单位经济拆解公式：

```
净贡献 = 平均收入 + 扩展收入 − 服务成本
LTV     = 净贡献 × 平均生命周期
          （生命周期 = 1 ÷ 月流失率，上限 120 个月）
回收月数 = CAC ÷ 净贡献
```

| 变量       | 含义                              |
| ---------- | --------------------------------- |
| `平均收入` | 每位客户每月基础订阅费             |
| `扩展收入` | 每位客户每月增购 / 附加收入        |
| `服务成本` | 托管、支持、支付处理等月度成本     |
| `月流失率` | 每月流失的客户百分比               |
| `CAC`      | 获客成本（销售 + 市场费用 ÷ 新增） |

规模化模型假设每 10× 客户增长带来 10% 服务成本下降（批量化托管、自动化、支持效率）。优化杠杆按 LTV 影响排序：降 1% 流失 vs 增 10% 扩展收入 — 影响更大的胜出。

## 局限性 / 何时不适用

本计算器假设流失稳定、服务成本线性。它不建模：（1）一次性 onboarding 成本（应在客户生命周期摊销）；（2）按用量定价（收入每月波动）；（3）多产品线交叉补贴。对于年度合同预付的 B2B SaaS，净贡献可能低估第一个月收入。对于 marketplace 或交易型业务，请用 take-rate 模型 —— 那类业务的单位经济由 GMV 驱动，不是订阅美元。

## 案例走读

假设一个 B2B SaaS：每月基础订阅 $100、扩展收入 $30、服务成本 $30、CAC $300、月流失 5%。

1. **净贡献** = $100 + $30 − $30 = **每位客户每月 $100**（76.9% 毛利率）
2. **平均生命周期** = 1 ÷ 5% = 20 个月
3. **LTV** = $100 × 20 = **$2,000**
4. **回收期** = $300 ÷ $100 = **3.0 个月** —— SaaS 顶级水准
5. **LTV:CAC** = $2,000 ÷ $300 = **6.7:1** —— 高于 3:1 健康线

规模化时：1 万客户 × $100 净贡献 = 每月毛利 $100 万，加上成本下降 10%（规模效应）后升到 $103 万/月。配合 **SaaS 估值计算器** 即可看到该 LTV:CAC 在收入倍数退出时的估值。
