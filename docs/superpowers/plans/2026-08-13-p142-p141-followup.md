- **Ship sequence per batch**:
  1. Implement commits on feature branch
  2. `git push origin feature/p142-p141-followup`
  3. `git checkout master && git merge --ff-only feature/p142-p141-followup`

  5. `git push github master --force-with-lease` (only if cron drift detected)
- **Subagent dispatch**: One implementer + one spec-verifier per task. MECH class — no quality reviewer (per `subagent-driven-overhead.md`).
- **Commit message convention**: `feat(check):` / `refactor(codegen):` / `fix(security):` / `fix(a11y):` / `docs(meta):`

const ROOT = resolve(__dirname, '..');
const TARGET_FILES = [

  const violations: string[] = [];
  for (const file of TARGET_FILES) {
    const content = readFileSync(resolve(ROOT, file), 'utf8');
    const lines = content.split('\n');
    lines.forEach((line, i) => {
      // Strip HTML comments first (P141-B2-T5 pattern)

});
