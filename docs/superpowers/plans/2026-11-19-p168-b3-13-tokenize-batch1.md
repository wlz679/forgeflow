## Global Constraints

- **英文页必须逐字不变**：token 的英文兜底必须与改写前的原文**逐字相同** ⇒ G9 守；兜底里多一个空格都算回归。
- **改写 = 重写整个引擎文件**：FAQ / description / howToUse 也在文件里 ⇒ 不许顺手改文案；要改必须同步 locale。
- **跨引擎共享 code 的英文必须逐字一致**：同名 label 若措辞不同 ⇒ 拆新 code，不许复用（B3-8 实测教训）。
- **locale 只走工具落库**：p168-locale-merge（保键序 + 占位符守恒 + emoji 取源）⇒ **禁止手改 locale JSON**。
- **翻译 worker 只产出「code→中文」清单**：不碰引擎文件、不碰 locale JSON ⇒ 落库永远走工具（B3-7 教训：别用正则批量改子 agent 的产出）。
- **模板不得冻结数值**：locale 模板里的数值会直接显示给用户 ⇒ 一切运行时数值必须走 {param}。
- **健康度 4 档各写一个 code 字面量**：动态拼码静态扫描认不出 ⇒ 会被守卫判成未声明。
- **staticExamples[0] 由 codegen 重生成**：不许手写（codegen-examples --check 会报漂移）。
- **目标状态型守卫必须与修复同 commit 落库**：每笔提交里「新增进 TOKENIZED 的引擎」必须已完全令牌化，否则 CI 红。
- **G9 基线钉在本批之前**：baseline = '94bffb2'（B3-13 令牌化之前的最后一个提交）⇒ **不得用 HEAD**（否则变成 token vs token 真空绿）。

- 一条变异只红一条断言；变异必须真的改到文件；还原无条件执行 + sha256 逐字节校验。
- 提交前 `git fetch` + 确认 0 behind；禁止 force-push；commit 信息 = `type(scope): 中文标题` + 正文含实测数字 + **维度 3 scan 声明**；不得含 `[CI Skip]` 类标记。

### Task 1: 全站 zh 整行英文测量工具（先红：拿到欠账基线）

**Files:**

**Interfaces:**
- Produces: `auditAll(): { slug: string; zhEn: number; cardLines: number }[]` —— 每引擎 zh 侧整行英文行数 + 卡片总行数（读 dist 产物）。
- CLI：`--json` 输出机器可读数组；默认输出按 zhEn 降序的表格 + 合计行。

- [ ] **Step 1: 写工具**（复用既有提取器 `isEnglishLine`，**不另写判据**）

```ts
import { readFileSync, existsSync } from 'node:fs';
import { resolve } from 'node:path';
import '../../src/engines/index.ts';
import { getAllEngines } from '../../src/core/engines/registry.ts';
import { staticCard, isEnglishLine } from './p168-card-text.mjs';

const ROOT = resolve(import.meta.dirname, '..', '..');

export function auditAll(): { slug: string; zhEn: number; cardLines: number }[] {
  const out: { slug: string; zhEn: number; cardLines: number }[] = [];
  for (const e of getAllEngines() as any[]) {
    const p = resolve(ROOT, 'dist', 'zh', e.slug, 'index.html');
    if (!existsSync(p)) continue;
    const card = staticCard(readFileSync(p, 'utf8'));
    out.push({ slug: e.slug, zhEn: card.filter(isEnglishLine).length, cardLines: card.length });
  }
  return out;
}

if (resolve(process.argv[1] ?? '') === resolve(import.meta.filename ?? '')) {
  const rows = auditAll().sort((a, b) => b.zhEn - a.zhEn);
  const todo = rows.filter((r) => r.zhEn > 0);
  if (process.argv.includes('--json')) {
    console.log(JSON.stringify(todo, null, 2));
  } else {
    for (const r of todo) console.log(String(r.zhEn).padStart(4) + ' / ' + String(r.cardLines).padStart(3) + '  ' + r.slug);
    console.log('—— ' + todo.length + ' 个引擎 · zh 整行英文合计 ' + todo.reduce((s, r) => s + r.zhEn, 0) + ' 行');
  }
}
```
