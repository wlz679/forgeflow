> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace 4 inline AI-cost preset-button JSX blocks in `[slug].astro` with a reusable `<PresetChips>` component driven by `engine.presets[]` field on the type.

**Architecture:** Add `Preset` interface to `core/engines/types.ts`. New `src/components/PresetChips.astro` consumes `engine.presets` (typed array). Migrate 4 AI cost engines from inline `PRESETS: Record<string, Record<string, string>>` const to `engine.presets: Preset[]` field. Refactor `[slug].astro` to render `<PresetChips>` when `engine.presets?.length > 0`. Preset keys are kebab-case to match i18n key naming.

**Tech Stack:** Astro 4.13.2 (component mode), TypeScript 5.6 strict mode, tailwindcss 4.3.1.

## Global Constraints

- `Preset` interface uses kebab-case `key` to match i18n key naming convention.
- Only 4 engines wired in this batch: `solopreneur-ai-image-cost-calculator`, `solopreneur-ai-training-cost-estimator`, `solopreneur-gpu-cloud-cost-calculator`, `solopreneur-ai-api-cost-comparison`.
- Other 96 engines still use legacy `PRESETS` const (out of scope).
- i18n keys `tools.${slug}.preset.${key}` already exist in `en.json` / `zh.json` (added in master P140 era).
- `PresetChips.astro` uses camelCase → kebab-case conversion (`data-${kebabCase(field)}` HTML attribute convention) to dispatch preset values to `customFn` runtime.
- Component takes 3 props: `presets`, `slug`, `lang`.

/**
 * One-click preset that fills a calculator inputs from a button click.
 * Rendered as a chip at the top of the form (above inputs) when `presets`

export interface Preset {
  /** Lookup key for i18n label via t(`tools.${slug}.preset.${key}`, lang) */

  /** input.name → value. Component converts camelCase → kebab-case for HTML data-attr */

}

### Task 2: Create `PresetChips.astro` component

**Files:**
- Create: `src/components/PresetChips.astro`

- [x] **Step 1: Write the component**

```astro
---
import type { Preset } from "../core/engines/types";
import { t } from "../i18n";

interface Props {
  presets: Preset[];
  slug: string;
  lang: string;
}
const { presets, slug, lang } = Astro.props;
const slugKey = slug.replace("solopreneur-", "");
---
<div class="mb-5">
  <span class="block text-xs font-medium text-gray-400 mb-2 uppercase tracking-wide">
    {lang === "zh" ? "🎭 场景预设" : "🎭 Scenario Sc"}
"
  </span>
  <div class="flex flex-wrap gap-1.5" id={`preset-buttons-${slugKey}`}>
    {presets.map(p => (
      <button
        type="button"
        class="preset-btn text-xs px-2.5 py-1.5 rounded-lg border border-gray-200 bg-gray-50 hover:border-[#7C3AED] hover:bg:bg-[#7C3AED]/5 transition-all"
        {...Object.fromEntries(
          Object.entries(p.fields).map(([k, v]) => [
            `data-${k.replace(/([A-Z])/g, "-$1").toLowerCase()}`,
            String(v),
          ])
        )}
      >
        {p.emoji} {t(`tools.${slug}.preset.${p.key}`, lang)}
      </button>
    ))}
  </div>
</div>
```
