# P150 i18n JSON Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move `src/i18n/translations.ts` (TS dict) to per-locale JSON files, updating all 6 consumer call sites atomically.

**Architecture:** One-shot migration script regenerable from `translations.ts` (run twice during dev: initial cutover and after translation-team edits). Replace import statement in `src/i18n/index.ts`. Hard cutover (no dual-support period). Delete `translations.ts` in same commit as JSON write.

**Tech Stack:** TypeScript 5.6, Astro 4.13.2, Vite 5.x (handles JSON imports natively), Node 20.19.4 for migration script.

## Global Constraints

- i18n JSON files must live at `src/i18n/locales/{en,zh}.json` (matches existing `src/i18n/` convention from master).
- Key naming kept verbatim from `translations.ts` — no namespace flattening.
- `multiline` strings (q/a in FAQ blocks) handled via regex `[\s\S]*?` lazy any-char.
- zh values for new keys: English placeholder (real translation deferred).
- No transition period — both source and target never coexist.
- Engine slugs use dot-separated namespaces, never forward slashes.

- [x] **Step 1: Write the migration script**

```javascript
// tmp/_migrate-translations.mjs
// ONE-SHOT: reads translations.ts, emits {en,zh}.json
import fs from "node:fs";
const content = fs.readFileSync("src/i18n/translations.ts", "utf8");
// Per-line regex: matches each entry { q: ..., a: ... } or 'key': { en: '...', zh: '...' },
const re = /^(\s*)['"]([^'"]+)['"]:?\s*\{\s*en:\s*(['"])((?:(?!\3).)*?)\3\s*,\s*zh:\s*(['"])((?:(?!\5).)*?)\5\s*,?\s*\}\s*,?\s*$/gm;
const en = {}, zh = {};
let m, count = 0;
while ((m = re.exec(content)) !== null) {
  en[m[2]] = m[4];
  zh[m[2]] = m[6];
  count++;
}
fs.mkdirSync("src/i18n/locales", { recursive: true });
fs.writeFileSync("src/i18n/locales/en.json", JSON.stringify(en, null, 2) + "\n");
fs.writeFileSync("src/i18n/locales/zh.json", JSON.stringify(zh, null, 2) + "\n");
console.log(`Migrated ${count} entries.`);
```
